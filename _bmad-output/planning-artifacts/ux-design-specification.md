## Executive Summary

### Project Vision

**sisys** 是面向大中型企业高管团队、企业战略与市场体系人员和专业顾问的 AI 驱动战略规划与决策智能平台。系统通过多 Agent 协作（CEO/CFO/CMO/CTO/COO/CHO/AUD 七种角色）和内置合规审计（7 年 WORM 存储），解决企业战略规划中的三大核心痛点：

1. **高管团队协调难** - 战略规划需要多角色视角，但高管时间难以协调，决策质量依赖个人经验
2. **数据分散决策难** - 决策质量依赖数据，但企业数据分散在不同系统，难以形成完整洞察
3. **流程长效率低** - 大中型企业战略规划参与人员多、流程长、效率低，从数周到数月不等

**核心价值主张：**

| 用户群体 | 核心价值 |
|---------|---------|
| **高管团队** (CEO/CFO/CTO 等) | 通过 AI 协作在几天内达成战略共识，而非数周会议；决策质量提升 40% |
| **企业战略与市场体系人员** | 标准化战略分析流程，快速获取专业洞察，减少重复性数据整理工作 |
| **专业顾问** | 3 小时完成原本需要 1 天的分析报告，效率提升 3 倍，输出质量标准化 |

### Target Users

**sisys 服务三类核心用户群体：**

| 用户类型 | 代表人物 | 核心需求 | 使用频率 |
|---------|---------|---------|---------|
| **高管团队** | CEO 张总、CFO 王总 | 快速战略共识、财务量化决策、风险全景视图 | 低（周/月） |
| **企业战略与市场人员** | 李经理、小刘、小陈 | 流程标准化、高保真溯源、报告自动生成 | 高（日/周） |
| **专业顾问** | 王经理（咨询）、赵经理（投资） | 白标输出、多租户隔离、项目交付效率 | 中（项目周期） |

**用户优先级：** MVP 阶段优先服务**企业战略与市场人员**（高频用户），同时提供**高管决策视图**（付费决策者）。

### Key Design Challenges

基于多方视角讨论，识别以下关键 UX 设计挑战：

1. **三视图切换复杂性** - 如何在同一系统中为三类不同用户提供差异化视图，同时保持一致性？

2. **多 Agent 协作可视化** - 如何将抽象的 AI 多角色辩论过程以直观、可理解的视觉方式呈现？

3. **高保真溯源体验** - 如何实现从结论到原始文档坐标点的精准跳转，同时保持流畅的交互体验？

4. **合规与简洁的平衡** - 如何在满足 SOX/ISO27001 合规要求的同时，为高管用户提供简化决策体验？

5. **信息密度差异化** - 高管视图需要低信息密度（30 秒决策），专业人员视图需要高信息密度（深度分析）

---

### Design Opportunities

基于竞争分析和用户痛点，识别以下设计机会：

1. **高管仪表盘差异化** - 打造"一眼决策"的高管视图，成为碾压性竞争优势

2. **溯源交互创新** - Bounding Box 级溯源可成为行业标杆体验

3. **白标品牌定制** - 为咨询/投行用户提供完全可定制的品牌体验，增强专业感

4. **财务量化可视化** - 敏感性分析龙卷风图、情景对比滑块等创新交互

5. **流程可视化透明** - BLM/BEM 阶段进度可视化，让用户随时知道位置和下一步

## Core User Experience

### Defining Experience

**核心用户体验定义：**

sisys 的核心用户体验是**从数据上传到战略决策的无缝闭环**。用户旅程的关键节点：

```
1. 上传数据（17 种格式） → 2. 自动解析 → 3. 选择分析工具 → 4. 多 Agent 协作分析
         ↓
5. 生成洞察 → 6. 高保真溯源验证 → 7. 财务量化 → 8. 高管审批 → 9. 战略落地追踪
```

**最关键的交互（必须完美）：**

| 交互 | 用户 | 期望体验 |
|------|------|---------|
| 高保真溯源 | 李经理（战略） | 30 秒内从结论跳转至原始文档坐标点 |
| 高管审批 | CEO 张总 | 30 秒内理解态势并做出决策 |
| 财务量化 | CFO 王总 | 每个战略建议自动显示 NPV/IRR/敏感性分析 |
| 白标报告 | 王经理（顾问） | 一键生成符合品牌规范的 PPT/PDF |
| 批量筛选 | 赵经理（投资） | 2 小时内完成 100 个项目初筛 |

### Platform Strategy

**平台策略决策：**

| 决策 | 选择 | 理由 |
|------|------|------|
| **主要平台** | Web 应用（响应式） | 企业用户主要在桌面端使用，支持跨设备访问 |
| **交互方式** | 鼠标/键盘为主 | 专业人员需要高效操作（快捷键、批量操作） |
| **PDF 渲染** | 内置阅读器（基于 PDF.js） | 支持 Bounding Box 高亮和坐标跳转 |
| **报告导出** | PPT/PDF（MVP）、Word（V1） | 覆盖高管汇报和顾问交付场景 |
| **企业集成** | 手动导入（MVP）、API 对接（V1） | MVP 快速验证，V1 深化集成 |
| **部署方式** | 本地部署/私有云优先 | 满足数据境内存储和合规要求 |

**技术约束对 UX 的影响：**

| 约束 | UX 应对策略 |
|------|-----------|
| 检索延迟 P95 <800ms | 骨架屏 + 进度反馈，减少感知等待 |
| 并发 Agent 会话 10 (MVP) | 排队指示 + 预计等待时间 + 后台处理通知 |
| Bounding Box 单页 (MVP) | 明确标注"单页溯源"，V1 扩展到多页 |

### Effortless Interactions

**必须 effortless 的交互：**

1. **数据上传与解析**
   - 拖拽上传 17 种格式
   - 自动解析并结构化提取
   - 进度可视化（后台处理，可继续其他工作）

2. **高保真溯源**
   - 点击结论 → 弹出溯源卡片
   - 点击"跳转" → 自动定位 PDF 坐标点
   - 置信度一目了然（高/中/低）

3. **多 Agent 辩论查看**
   - 时间线视图展示辩论过程
   - 风险热力图（红/黄/绿）
   - 一键展开详细论据

4. **财务量化查看**
   - 每个战略建议旁显示 NPV/IRR
   - 点击展开敏感性分析（龙卷风图）
   - 情景对比滑块（拖动看变化）

5. **Checkpoint 审批**
   - 异步审批（高管随时随地）
   - 关键信息摘要（1 屏内）
   - 一键批准/修正/拒绝

**当前用户痛点（竞品不足）：**

| 痛点 | 竞品表现 | sisys 解决方案 |
|------|---------|--------------|
| 数据溯源 | 人工查找 1-2 小时 | 30 秒自动跳转 |
| 高管审批 | 集中开会 2-3 周 | 异步审批 3-5 天 |
| 报告格式 | 手动调整 1 天 | 一键生成 1 小时 |
| 项目筛选 | 人工 200 小时/100 项目 | 自动 2 小时/100 项目 |

### Critical Success Moments

**决定成败的关键时刻：**

| 时刻 | 用户 | 成功标准 | 失败后果 |
|------|------|---------|---------|
| **第一次溯源** | 李经理 | 30 秒内跳转到原始文档 | 失去信任，不再使用 |
| **第一次高管审批** | CEO 张总 | 30 秒内理解并决策 | 认为系统太复杂，放弃使用 |
| **第一次财务量化** | CFO 王总 | 看到 NPV/IRR/敏感性分析 | 认为不够专业，无法向董事会汇报 |
| **第一次白标报告** | 王经理（顾问） | 品牌元素 100% 准确 | 无法交付客户，失去付费动力 |
| **第一次批量筛选** | 赵经理（投资） | 2 小时内完成 100 项目 | 效率提升不明显，不付费 |

**首次用户成功路径（Onboarding）：**

```
Day 1: 上传文档 → 自动解析 → 运行第一个分析工具 → 看到洞察
Day 2: 验证溯源 → 查看财务量化 → 生成第一份报告
Day 3: 邀请高管审批 → 获得反馈 → 完成第一个 Checkpoint
```

### Experience Principles

**指导 UX 设计的核心原则：**

| 原则 | 描述 | 设计含义 |
|------|------|---------|
| **30 秒原则** | 高管视图必须在 30 秒内理解并决策 | 第一屏只显示 3 个关键指标、红/黄/绿状态指示器、渐进式披露详情 |
| **溯源即信任** | 每个数据/结论必须可追溯至原始来源 | Bounding Box 跳转、置信度颜色 + 文字双重编码、溯源路径面包屑、悬浮弹窗 |
| **财务量化必备** | 每个战略建议必须有财务影响分析 | NPV/IRR/敏感性分析内置、情景对比滑块、数据准确率 100% |
| **品牌即价值** | 顾问报告必须 100% 符合品牌规范 | 可视化品牌编辑器、一键应用模板、导出时间<1 分钟 |
| **流程透明** | 用户随时知道进度和下一步 | BLM/BEM 阶段可视化、Checkpoint 明确、骨架屏模拟真实内容结构 |
| **合规内建** | 审计追踪不打扰但完整 | 后台记录、按需查询、合规清单、WORM 存储 7 年 |
| **AI 透明性** | 用户知道 AI 在做什么、为什么 | 显示 Agent 思考过程、工具使用日志、置信度评分、排队指示 + 预计等待时间 |

### Emotional Design Principles

**情感化设计原则：**

| 原则 | 描述 | 应用示例 |
|------|------|---------|
| **先情感后功能** | 用户先感受，后思考 | 仪表盘先用颜色传达状态，再用数字传达细节 |
| **峰值时刻设计** | 创造让用户记住的瞬间 | 第一次溯源成功时的流畅体验 + 绿色对勾动画 |
| **透明建立信任** | AI 行为可见可理解 | 显示 Agent 思考过程、工具使用、置信度 |
| **渐进式披露** | 避免信息过载 | 第一屏 3 个指标，点击后展开详情 |
| **友好错误处理** | 错误时保持用户信心 | "数据解析失败，请检查格式"而非"Error 500" |
| **庆祝小胜利** | 强化成就感 | Checkpoint 完成时的进度庆祝动画 |
| **预警平衡设计** | 警觉性 + 可控感 | 预警显示等级 + 影响 + 建议措施 |

#### 导航模式

### Anti-Patterns to Avoid

**UX 反模式（避免）：**

| 反模式 | 问题 | 为什么避免 | 替代方案 |
|-------|------|-----------|---------|
| **信息过载仪表盘** | 第一屏显示 20+ 指标 | 高管无法 30 秒理解，失去掌控感 | 第一屏只显示 3 个关键指标 |
| **跳转新页面溯源** | 点击溯源打开新标签页 | 上下文切换，失去专注感 | 悬浮弹窗，保持当前上下文 |
| **仅显示数字无含义** | 只显示"NPV ¥12 亿" | CFO 不知道是否好，失去自信 | 显示"NPV ¥12 亿（高于资本成本 15%）✅" |
| **只报警无建议** | 预警只显示"风险高" | 增加焦虑，不增加可控感 | 预警 + 等级 + 影响 + 建议措施 |
| **魔法般 AI 结果** | 只显示结果不显示过程 | 技术用户不信任，怀疑可靠性 | 显示 Agent 思考过程 + 工具使用 |
| **模糊错误提示** | "Error 500"或"解析失败" | 用户不知道如何修复，挫败感 | "数据解析失败，请检查是否为 PDF/Excel 格式" |
| **无限加载无反馈** | 转圈 loading 无进度 | 用户焦虑，不知道要等多久 | 进度条 + 预计完成时间 |
| **强制同步等待** | 必须等待处理完成 | 效率低，用户无法做别的 | 后台处理 + 完成通知 |
