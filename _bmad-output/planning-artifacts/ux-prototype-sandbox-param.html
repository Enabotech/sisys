BLM 战略环 ↔ BEM 执行环 双环联动

🔵 BLM 战略环 — "做正确的事"

市场洞察 → 宏观环境 + 竞争分析（参数 1~17）
战略意图 → 愿景、目标、节奏（参数 18~27）
创新焦点 → 产品/模式/运营创新
业务设计 → 客户选择、价值主张、盈利模式（参数 28~34）
📋 输出：SP 战略规划文档 | 🎯 产物：战略控制点(SC)、战略目标 | 👤 角色：CEO/CSO/CFO

🟢 BEM 执行环 — "把事做正确"

战略解码 → SP→CSF→KPI→BP 举措（参数 35~44）
目标分解 → 组织→部门→个人 PBC
资源匹配 → 预算/人力/供应链配置（参数 45~52）
执行监控 → 进度跟踪、偏差分析
评估复盘 → 结果评价、差距反馈（参数 53~56）
📋 输出：BP 年度经营计划 | 🎯 产物：年度举措、KPI 责任书、预算分配表 | 👤 角色：CSO/COO/CFO/CHO

三重信任分与双环的参数映射

🎯 方向可信

"我们的战略方向对吗？"

f(宏观环境×0.25 + 竞争格局×0.25 + 战略意图×0.3 + 业务设计×0.2)
BLM战略环 参数 1~34

🔗 解码可信

"战略翻译成执行了吗？"

f(SP-BP映射完整度×0.4 + CSF覆盖率×0.3 + 验证通过率×0.3)
BEM执行环·前半段 参数 35~44

✅ 执行可信

"有能力执行并取得结果吗？"

f(资源匹配度×0.35 + 人才就绪度×0.35 + 结果可行性×0.3)
BEM执行环·后半段 参数 45~56

第一层 · 宏观环境参数 BLM战略环 市场洞察·宏观分析 | 对标 PESTEL

#参数键中文名单位定义
1mkt_size_tam总可用市场¥亿Total Addressable Market — 如果100%渗透的理想市场规模
2mkt_size_sam可服务市场¥亿Serviceable Available Market — 受制于地理/渠道/能力的可及市场
3mkt_growth_cagr市场增速%未来3-5年复合年增长率
4policy_support_level政策支持度1-5产业政策/补贴/税收优惠/准入便利综合评估（5=强支持）
5regulatory_risk监管风险1-5合规/牌照/审查/处罚风险评估（5=极高风险）
6tech_maturity技术成熟度TRL 1-9NASA技术就绪水平——核心技术达到哪个TRL等级
7macro_sensitivity宏观周期敏感度1-5收入对GDP/CPI/利率等的敏感程度（5=极敏感）
8esg_pressureESG压力指数1-5环境披露/社会责任/治理合规的外部压力（5=极强压力）
9demand_elasticity需求价格弹性系数价格变动1%导致需求变动的百分比（>1=弹性，<1=刚性）

#参数键中文名单位定义

11comp_count_direct直接竞争者数家同品类/同价格带/同目标客群的竞争对手

14substitution_threat替代品威胁1-5替代方案的可获得性/性价比/客户转换成本（5=极高威胁）
15new_entrant_barrier进入壁垒1-5资金/技术/渠道/品牌综合壁垒（5=极高壁垒=好）

17supplier_concentration供应商集中度%Top3供应商采购占比（高=受制于人）
