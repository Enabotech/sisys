## 执行摘要

### 统一原则

本统一路线图基于以下核心原则：

1. **系统整体视角** - 从端到端价值流出发，而非单点功能堆砌
2. **商业价值优先** - 每个版本必须验证明确的商业假设
3. **技术可行性** - 架构能力必须支撑功能承诺
4. **用户体验一致** - 三视图（高管/专业人员/顾问）体验差异化但质量一致

### 版本定义统一

| 版本 | 时间窗口 | 核心目标 | 成功标准 | 目标客户 |
|------|---------|---------|---------|---------|
| **MVP** | 0-3 个月 | 验证核心价值假设 | 3-5 家付费试点，NPS≥30 | 顾问群体（个人专业版） |
| **V1** | 3-6 个月 | 企业级能力验证 | 20 家企业客户，¥3000 万 ARR | 中型企业（企业版） |
| **V2** | 6-12 个月 | 完整合规 + 行业深耕 | 100 家企业，¥3 亿 ARR | 大型企业 + 金融机构 |
| **V3** | 12-36 个月 | 生态构建 + 全球化 | 500-1000 家，¥10-25 亿 ARR | 跨国企业 + 生态伙伴 |

## 第一部分：MVP 范围定义（0-3 个月）

### MVP 核心假设验证

**假设 1：效率提升假设**
- 顾问使用 sisys 可在 3 小时内完成原本需要 1 天的分析报告
- 验证方式：A/B 测试，10 个顾问项目对比

**假设 2：决策质量假设**
- 多 Agent 辩论可识别传统会议忽略的重大风险
- 验证方式：回溯分析，对比 sisys 输出与高管会议记录

**假设 3：信任建立假设**
- 高保真溯源可在 30 秒内回应高管数据质疑
- 验证方式：用户测试，20 次溯源场景计时

**假设 4：付费意愿假设**
- 顾问愿意为效率提升和白标输出付费
- 验证方式：销售转化，3-5 家付费试点

## 第九部分：统一决策记录

### 决策 1：MVP 聚焦顾问群体而非企业客户

**决策内容：** MVP 阶段聚焦顾问群体（个人专业版），而非直接进攻企业客户

**理由：**
1. 顾问决策链条短（个人决策 vs 企业采购委员会）
2. 顾问效率提升易感知（3 小时 vs 1 天）
3. 顾问白标输出可直接交付客户，付费动力强
4. 顾问口碑传播可自然形成企业获客

**影响：**
- MVP 功能优先级向顾问倾斜（白标输出、多项目管理）
- 企业级功能（完整多 Agent 协作、BEM 流程）延至 V1
- 销售策略从企业直销转向顾问群体口碑营销

---

### 决策 2：高保真溯源作为核心定义性体验

**决策内容：** Bounding Box 坐标级溯源作为 sisys 的核心定义性体验，MVP 必须完美

**理由：**
1. 全员使用（高管/专业人员/顾问）
2. 使用频次高（商业分析师 5-10 次/天）
3. 情感冲击强（"30 秒溯源，这比以前快太多了！"）
4. 差异化明显（竞品完全没有）
5. 信任建立第一步（数据可信→系统可信→建议可信）

**影响：**
- MVP 资源优先保障溯源体验（PDF.js + 坐标映射）
- 溯源响应时间<300ms 作为 P0 指标
- Bounding Box 定位准确率≥95%（单页）作为验收标准

---

### 决策 3：EIP 隔离协议分阶段实现

**决策内容：** EIP 弹性视角隔离协议分阶段实现，MVP 简化为 L4 硬隔离

**理由：**
1. EIP 实现复杂度高（动态升降级算法、审批链管理）
2. MVP 核心价值验证不依赖动态隔离
3. 顾问群体主要为单兵作战，协作需求低
4. 企业客户才有多 Agent 协作强需求

**影响：**
- MVP 仅实现 L4 硬隔离（Prompt/工具/数据三重隔离）
- V1 实现动态升降级（基于任务依赖/关键词频率/SYS 命令）
- V2 实现完整 EIP（L1-L4 四级隔离，自动恢复机制）

---

### 决策 4：UDMR 动态路由 MVP 采用静态规则

**决策内容：** UDMR 统一动态模型路由框架 MVP 采用静态规则（简单任务本地/复杂任务云端）

**理由：**
1. 动态评分算法需要历史数据训练
2. MVP 阶段路由量不足以支撑准确评分
3. 静态规则可满足基本成本优化需求
4. V1 阶段有足够数据后可切换动态评分

**影响：**
- MVP 路由规则：简单检索/摘要→本地，复杂战略分析/多 Agent 辩论→云端
- V1 实现四因子评分（语义匹配 35% + 历史成功率 30% + 成本效率 20% + 任务复杂度 15%）
- V1 目标本地路由占比≥80%，成本节省≥50%

---

### 决策 5：合规认证分阶段推进

**决策内容：** 合规认证分阶段推进，MVP 等保 2.0 基础，V1 SOX/ISO27001，V2 银保监会规范

**理由：**
1. 合规认证成本高（等保 2.0 ¥20-30 万，SOX/ISO27001 ¥30-50 万/项）
2. 认证周期长（3-6 个月/项）
3. MVP 阶段顾问群体对合规要求低
4. 企业客户才需要完整合规认证

**影响：**
- MVP 合规预算：¥20-30 万（等保 2.0 基础）
- V1 合规预算：¥60-100 万（等保 2.0 完整 + SOX/ISO27001）
- V2 合规预算：¥100-200 万（银保监会规范 + 行业特定合规）
