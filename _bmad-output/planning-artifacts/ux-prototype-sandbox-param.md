# SISYS 组织级统一参数体系

> 基于 IBM BLM（业务领导力模型）+ 华为 BEM（业务执行模型），对标 PESTEL / Porter Five Forces / Balanced Scorecard / OKR / McKinsey 7S 等业界最佳实践

---

## 一、方法论基础

### BLM（业务领导力模型）— 战略环

IBM 与哈佛商学院 2003 年联合开发，华为 2009 年引入。核心命题：**战略是由不满意激发的——对业绩差距和机会差距的不满意。**

BLM 战略环覆盖四个阶段：
- **市场洞察**：宏观环境分析 + 竞争分析 + 客户分析 → "我们在哪里？"
- **战略意图**：愿景、战略目标、近期目标 → "我们要去哪里？"
- **创新焦点**：产品创新、商业模式创新、运营创新 → "如何差异化？"
- **业务设计**：客户选择、价值主张、盈利模式、战略控制点 → "如何赢？"

BLM 还定义了四个组织保障维度（关键任务、人才、正式组织、文化与氛围），这些在 BEM 中落地。

### BEM（业务执行模型）— 执行环

华为在 BLM 基础上自研。核心命题：**战略解码是 SP 到 BP 的翻译过程——确保"战略能落地"。**

BEM 执行环覆盖四个阶段：
- **战略解码**：SP 控制点 → CSF 关键成功因素 → KPI → BP 年度举措 → "战略翻译成动作"
- **目标分解**：组织目标 → 部门目标 → 个人 PBC → "责任到人"
- **资源匹配**：预算分配、人力配置、供应链保障 → "有能力做"
- **执行监控与评估复盘**：进度跟踪、偏差分析、结果评价、差距反馈 → "做得好不好"

### BLM ↔ BEM 的双环联动

```
┌─────────────────────────────────────────────────────┐
│                    BLM 战略环                         │
│                                                     │
│  ┌──────────┐   ┌──────────┐   ┌──────────┐         │
│  │ 市场洞察  │ → │ 战略意图  │ → │ 创新焦点  │         │
│  │ (看外部)  │   │ (定方向)  │   │ (找差异)  │         │
│  └──────────┘   └──────────┘   └─────┬────┘         │
│                                      ↓               │
│                               ┌──────────┐           │
│                               │ 业务设计  │           │
│                               │ (定模式)  │           │
│                               └─────┬────┘           │
│                                     │                │
│  输出: SP 战略规划文档              │                │
│  产物: 战略控制点(SC)、战略目标      │                │
│  角色: CEO/CSO/CFO                 │                │
└─────────────────────────────────┬───────────────────┘
                                  │ SP→BP 解码 · 交接点
┌─────────────────────────────────▼───────────────────┐
│                    BEM 执行环                         │
│                                                     │
│  ┌──────────┐   ┌──────────┐   ┌──────────┐         │
│  │ 战略解码  │ → │ 目标分解  │ → │ 资源匹配  │         │
│  │ (翻译)    │   │ (下放)    │   │ (配给)    │         │
│  └──────────┘   └──────────┘   └─────┬────┘         │
│                                      ↓               │
│  ┌──────────┐   ┌──────────┐                        │
│  │ 评估复盘  │ ← │ 执行监控  │                        │
│  │ (反馈)    │   │ (追踪)    │                        │
│  └──────────┘   └──────────┘                        │
│                                                     │
│  输出: BP 年度经营计划                                │
│  产物: 年度举措、KPI 责任书、预算分配表                 │
│  角色: CSO/COO/CFO/CHO                             │
└─────────────────────────────────────────────────────┘
```

**关键洞察：** BLM 回答"做正确的事"，BEM 回答"把事做正确"。**三重信任体系直接映射到这两个环：方向可信+解码可信 = BLM 环的输出质量，执行可信 = BEM 环的输出质量。**

## 三、三重信任分与双环的参数映射

| 信任维度 | 含义 | 对应环 | 公式参数来源 | 权重 |
|---|---|---|---|---|
| 🎯 **方向可信** | "我们的战略方向对吗？" | BLM战略环 | 宏观环境 + 竞争格局 + 战略意图 + 业务设计 | 0.25 + 0.25 + 0.3 + 0.2 |
| 🔗 **解码可信** | "战略翻译成执行了吗？" | BEM执行环·前半段 | SP-BP映射完整度 + CSF覆盖率 + 验证通过率 | 0.4 + 0.3 + 0.3 |
| ✅ **执行可信** | "有能力执行并取得结果吗？" | BEM执行环·后半段 | 资源匹配度 + 人才就绪度 + 结果可行性 | 0.35 + 0.35 + 0.3 |

## 四、详细参数定义

### 第一层：宏观环境参数 — BLM战略环·市场洞察（9个）

> **对标：** PESTEL（政治/经济/社会/技术/环境/法律）
> **核心问题：** 宏观环境有利吗？

| # | 参数键 | 中文名 | 单位 | 定义 |
|---|---|---|---|---|
| 1 | `mkt_size_tam` | 总可用市场 | ¥亿 | Total Addressable Market — 如果100%渗透的理想市场规模 |
| 2 | `mkt_size_sam` | 可服务市场 | ¥亿 | Serviceable Available Market — 受制于地理/渠道/能力的可及市场 |
| 3 | `mkt_growth_cagr` | 市场增速 | % | 未来3-5年复合年增长率 |
| 4 | `policy_support_level` | 政策支持度 | 1-5 | 产业政策/补贴/税收优惠/准入便利综合评估（5=强支持） |
| 5 | `regulatory_risk` | 监管风险 | 1-5 | 合规/牌照/审查/处罚风险评估（5=极高风险） |
| 6 | `tech_maturity` | 技术成熟度 | TRL 1-9 | NASA技术就绪水平——核心技术达到哪个TRL等级 |
| 7 | `macro_sensitivity` | 宏观周期敏感度 | 1-5 | 收入对GDP/CPI/利率等的敏感程度（5=极敏感） |
| 8 | `esg_pressure` | ESG压力指数 | 1-5 | 环境披露/社会责任/治理合规的外部压力（5=极强压力） |
| 9 | `demand_elasticity` | 需求价格弹性 | 系数 | 价格变动1%导致需求变动的百分比（>1=弹性，<1=刚性） |

### 第二层：竞争格局参数 — BLM战略环·市场洞察（8个）

> **对标：** Porter Five Forces（竞争/替代品/客户/供应商/新进入者）
> **核心问题：** 竞争位置好吗？

| # | 参数键 | 中文名 | 单位 | 定义 |
|---|---|---|---|---|
| 10 | `mkt_concentration` | 市场集中度 | % | Top3品牌合计市场份额 |
| 11 | `comp_count_direct` | 直接竞争者数 | 家 | 同品类/同价格带/同目标客群的竞争对手 |
| 12 | `comp_lead_months` | 竞品先发优势 | 月 | 主要竞争对手领先的时间窗口 |
| 13 | `comp_rd_intensity` | 竞品研发强度 | % | 主要竞品研发支出/营收比 |
| 14 | `substitution_threat` | 替代品威胁 | 1-5 | 替代方案的可获得性/性价比/客户转换成本（5=极高威胁） |
| 15 | `new_entrant_barrier` | 进入壁垒 | 1-5 | 资金/技术/渠道/品牌综合壁垒（5=极高壁垒=好） |
| 16 | `customer_concentration` | 客户集中度 | % | Top5客户收入占比（高=议价力弱） |
| 17 | `supplier_concentration` | 供应商集中度 | % | Top3供应商采购占比（高=受制于人） |

### 第三层：战略意图参数 — BLM战略环·战略意图+创新焦点（10个）

> **对标：** OKR 中的 Objectives、Balanced Scorecard 财务维度
> **核心问题：** 方向定得对吗？

| # | 参数键 | 中文名 | 单位 | 定义 |
|---|---|---|---|---|
| 18 | `revenue_target_3y` | 三年营收目标 | ¥亿 | SP规划期末年营收 |
| 19 | `mkt_share_target` | 市场份额目标 | % | 规划期末目标市占率 |
| 20 | `gross_margin_target` | 毛利率目标 | % | 规划期末综合毛利率 |
| 21 | `innovation_revenue_ratio` | 创新收入占比 | % | 近3年新产品/新业务收入占总收入比例 |
| 22 | `patent_count_target` | 专利目标 | 项 | 年度新增发明专利申请数 |
| 23 | `brand_awareness_target` | 品牌认知度 | % | 目标客户群中提示后认知率 |
| 24 | `channel_coverage_target` | 渠道覆盖率 | % | 目标渠道中已有覆盖的比例 |
| 25 | `ecosystem_partners_target` | 生态伙伴数 | 家 | 战略合作/渠道/技术伙伴总数 |
| 26 | `geographic_expansion` | 区域扩张度 | % | 非总部所在大区收入占总收入比例 |
| 27 | `esg_rating_target` | ESG评级目标 | 等级 | 规划期末 MSCI / 中证 / 万得 ESG评级 |

### 第四层：业务设计参数 — BLM战略环·业务设计（7个）

> **对标：** McKinsey 7S、Balanced Scorecard 客户+流程维度
> **核心问题：** 模式设计得通吗？

| # | 参数键 | 中文名 | 单位 | 定义 |
|---|---|---|---|---|
| 28 | `value_prop_clarity` | 价值主张清晰度 | 1-5 | 客户价值主张的差异化程度与认知一致性（5=极清晰） |
| 29 | `profit_model_viability` | 盈利模式可行性 | 1-5 | 收入流×成本结构的可持续性（5=极可行） |
| 30 | `core_competency_match` | 核心能力匹配度 | 1-5 | 业务设计所需能力与现有能力的差距（5=完全匹配） |
| 31 | `strategic_control_strength` | 战略控制点强度 | 1-5 | 护城河/客户粘性/转换成本综合（5=极强控制） |
| 32 | `customer_retention_rate` | 客户留存率 | % | 年度客户续约/复购率 |
| 33 | `time_to_market_months` | 产品上市周期 | 月 | 从立项到首批交付的端到端周期 |
| 34 | `portfolio_balance` | 产品组合均衡度 | 1-5 | 不同生命周期/风险等级产品的均衡分布（5=极均衡） |

### 第五层：战略解码参数 — BEM执行环·战略解码+目标分解（10个）

> **对标：** OKR 中的 Key Results、BSC 流程维度
> **核心问题：** 战略翻译得准吗？

| # | 参数键 | 中文名 | 单位 | 定义 |
|---|---|---|---|---|
| 35 | `sp_bp_alignment_rate` | SP-BP映射完整度 | % | 有明确BP举措支撑的SP控制点比例 |
| 36 | `csf_coverage_rate` | CSF覆盖度 | % | 关键成功因素被至少一个BP举措覆盖的比例 |
| 37 | `kpi_cascading_depth` | KPI穿透层级 | 层 | KPI从公司→部门→个人的分解层级数（理想≥3） |
| 38 | `initiative_interdependency` | 举措依赖复杂度 | 条 | BP举措之间的前置/依赖关系总数 |
| 39 | `resource_conflict_count` | 资源冲突点 | 个 | 多个BP举措争夺同一预算/人力/产能的冲突 |
| 40 | `budget_gap_pct` | 预算缺口率 | % | (BP举措预算总需求-已分配)/总需求 |
| 41 | `hc_gap_pct` | 人力缺口率 | % | (BP举措人力总需求-在岗)/总需求 |
| 42 | `owner_accountability` | 责任人明确度 | % | 有明确的唯一负责人的BP举措比例 |
| 43 | `milestone_achieve_rate` | 里程碑达成率 | % | 按计划时间完成的里程碑占全部里程碑比例 |
| 44 | `verification_pass_rate` | 解码验证通过率 | % | 通过"确认/存疑/需重做"三重验证的BP举措比例 |

### 第六层：执行与结果参数 — BEM执行环·资源匹配+执行监控+评估复盘（12个）

> **对标：** Balanced Scorecard 学习成长+财务维度
> **核心问题：** 有能力执行吗？结果好吗？

| # | 参数键 | 中文名 | 单位 | 定义 |
|---|---|---|---|---|
| 45 | `rd_budget_utilization` | 研发预算执行率 | % | 实际研发投入/预算（偏差>±15%视为异常） |
| 46 | `sales_cost_ratio` | 销售费用率 | % | 销售费用/营收（对标行业P25/P50/P75） |
| 47 | `supply_chain_efficiency` | 供应链效率 | % | 实际单位成本/基准单位成本 |

| 51 | `employee_engagement` | 员工敬业度 | 1-5 | 组织健康度/员工投入度（对标Gallup Q12） |

| 53 | `roi_payback_years` | 投资回收期 | 年 | 初始投资全额回收所需年数 |
| 54 | `npv_expected` | 预期净现值 | ¥亿 | 全生命周期折现净现值 |
| 55 | `downside_risk_exposure` | 下行风险敞口 | % | 最差情景下收入/利润损失比例 |
| 56 | `scenario_resilience` | 情景弹性 | 1-5 | 战略在多种情景中的表现稳定性（5=极稳定） |
