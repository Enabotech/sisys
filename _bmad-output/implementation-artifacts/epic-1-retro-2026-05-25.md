## 五、跨 Story 模式分析

### 5.1 层间接口适配

贯穿整个 Epic 的核心挑战：领域层抽象与基础设施层实现之间的桥梁
- 最终模式：领域层 Protocol 接口 + 基础设施层 Adapter 实现 + 应用层编排

### 5.2 审查反馈最高频问题

1. **边界防护缺失**（最高频）：状态转换无最终防护、参数无上下文错误
2. **Optional 字段不一致**：nullable=True 与上游 Optional 标注不匹配
3. **锁策略错误**：async 上下文使用 threading.Lock
4. **Config 注入错误**：领域服务接受 Config 对象而非原始值
5. **DI 注册格式**：未使用 `lambda resolver:` 格式
6. **PublishResult 未检查**：事件发布后未检查 `is_full_failure`
