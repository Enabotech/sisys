# SISYS V3.2 ASCII 线框图 — 5 张完整原型

> 设计演化: V1 (单卡) → V2 (6卡) → V3 (12卡Grid+Ghost) → V3.1 (后果树+双向传染+政治安全) → **V3.2 (单焦点卡+检测条+参数抽屉)**
>
> **核心设计决策 (2025-11-17 五方共识):** "One screen. One focus. One slider."
> 不是 12 张卡片的网格。不是 28 张卡片的墙。
> **一张焦点卡 + 一条检测条 + 一根全局滑块。**

---

## 设计常量 & 数据源

```
DESIGN TOKENS (继承 V3.1, V3.2 新增标记✨):
  画布: 1440×900px (高管 14" 笔记本标准)
  侧边条折叠宽: 24px ✨
  侧边条展开宽: 280px ✨
  焦点卡区: calc(100% - 24px - 32px) ≈ 1384px 居中
  滑块区高: 56px (含参数字段)
  参数抽屉高: 520px (从滑块区下展开)
  计数区高: 条件性 44px
  政治安全区高: 52px (固定 footer)
  头部高: 48px

  检测条点: 16px 直径, 间距 4px (28 点 = 28×16 + 27×4 = 556px 总高, 可滚动)
  颜色体系 (不变): green ≥70 / amber 40-69 / red <40
  检测态: 蓝脉冲 #3B82F6 ✨

  数据水印: 🔶 模拟数据 (半透明, 每张焦点卡 footer)
  动画时序:
    滑块拖动实时: 200ms 节流 ✨
    检测条涟漪: 50ms 延迟 (滑块释放后) ✨
    热点路径: 焦点卡+直接依赖 实时更新
    暖路径: 全部 28 卡 50ms 批量
    条展开: 300ms spring-bounce
    抽屉滑出: 350ms spring-settle
    模式切换: 400ms crossfade

  数据源 (来自 V3.1 原型):
    COMMITMENT_DEFS: 12 → 扩展至 28 ✨
      原 12 卡 + 16 新卡 (按六域展开: 北极星/能力/健康度/合规/创新/生态)
    PARAM_REGISTRY: 26 → 扩展至 98 ✨
      按 6 层组织: 环境(15) / 战略(22) / 执行(28) / 监控(14) / 风险(12) / 解码(7)
      预设参数(3): 国产化率 / 渠道覆盖率 / 研发投入占比
    sensitivity 表: 28 卡 × N 参数 (由 parameter-vector 模型替代原预计算 101 位表)
```

### Wireframe 1 行为注解

| 区域 | 行为 | 时序 |
|------|------|------|
| 检测条 (折叠) | 24px 宽。28个彩色点，按严重度排序(红顶→琥珀中→绿底)。当前检测项(supplier_local)蓝脉冲动画。hover 整条→300ms 展开至280px。 | 展开: 300ms spring-bounce `cubic-bezier(0.34,1.56,0.64,1)` |
| 焦点卡 | 始终显示被检测卡片(或用户选中卡片)。完整后果树: Operational Signal / Trigger Assumption / 受影响合同(表格) / 受影响的供应商 / 风险传导节点 / AI 异议(默认展开) / Path Back to Green。 | 内容伴随从检测条选择: 250ms fadeIn + slide |
| AI 异议 | 默认展开显示3个Agent异议。点击"▲ 收起"折叠。 | 折叠: 200ms ease-out |
| 风险节点 | 显示角色名"采购总监"而非"王立明"。公开视图保护隐私。点选→反向传染→滑块脉冲提示恢复位置。 | 脉冲: 1.2s 循环 |
| 滑块标签 | 显示 WHY 检测信息: "🔵 国产化率目标 — 供应商达标签约率连续3月下降"。右侧▾按钮打开参数抽屉。 | 抽屉: 350ms slide-down |
| 数据水印 | 焦点卡 footer 半透明 🔶 模拟数据，像素级不可忽略。 | 始终可见 |
| 时间戳 | "更新于 2h前" — 每卡独立动态时间。检测卡显示检测时间，非检测卡显示最后数据刷新时间。 | 30s 轮询刷新 |
| 计数区 | 条件性显示: 滑块移动时 / 检测触发时 / 幽灵预览时。正常静止态隐藏。 | 出现: 200ms fadeIn |
| 政治安全区 | 固定 footer, 始终可见当有检测项。48h静默倒计时实时递减。 | 30s 更新周期 |

### Wireframe 2 行为注解

## 数据模型变更: Ghost Manifest v3.2

```
V3.1 模型 (旧):
  ghostManifest = {0..100: {cardId: {score, color, label}}}
  = 101 位 × 12 卡 = 1212 记录
  预计算, 滑块拖动时查表 O(1)

V3.2 模型 (新):
  parameterVector = {
    localization: 67,     // 国产化率
    channel_cov: 52,      // 渠道覆盖率
    rd_invest: 8.2,       // 研发投入占比
    // ... 98 参数
  }

  scoreFormula(cardId, paramVector) → score
    // 每卡有独立公式: baseScore + Σ(param_i × sensitivityCoeff_i)
    // 敏感度系数表预定义, 非零系数约 3-8 个/卡
    // 实时计算, 复杂度 O(params_with_coeff) ≈ O(6) per card

  热点路径 (滑块拖动时, 200ms 节流):
    focusCard: 实时重算 (1 卡)
    directDependencies (affects[]): 实时重算 (1-4 卡)
    → 总: 2-5 卡实时, 其余卡不变直到释放

  暖路径 (滑块释放后, 50ms 延迟):
    全部 28 卡批量重算
    → 检测条颜色涟漪更新 (28 点 × 20ms 延迟, 按敏感度排序)

  预设参数 (3 快速切换):
    presets = [
      {id:'localization', name:'国产化率', default:67, tier:'环境'},
      {id:'channel_cov',  name:'渠道覆盖率', default:52, tier:'战略'},
      {id:'rd_invest',    name:'研发投入占比', default:8.2, tier:'执行'}
    ]

  参数切换开销:
    预计算不存在了。每次参数切换触发全部 28 卡重算。
    但由于每卡仅 3-8 个非零系数, 总计算 ≤ 224 次乘法, 远低于 16ms 帧预算。
```
