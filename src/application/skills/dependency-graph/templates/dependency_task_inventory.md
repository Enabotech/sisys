# 任务依赖清单采集表

> 工作坊现场填写；采集字段与 SKILL.md `input_schema` 一一对应（task_list 为顶层
> 对象数组，以分区标题承载，分区内字段即 Schema 叶子键——name 与 dependencies）。
> 确定性校验规则见 `references/validation_rules.md`。

## 基本信息

| 字段 | 说明 |
| --- | --- |
| 项目名称 | 目标项目/里程碑名称 |
| 计划周期 | 如 2026-Q4 版本周期 |
| 工作坊日期 | 填写日期 |
| 引导者/记录员 | 名字 |

## 采集表格

### task_list

逐任务一组 2 行（任务名 + 前置任务列表）。任务名禁含顿号「、」与箭头「←」；前置列表以顿号分隔、无前置填「无」。

任务 1：

| 字段 | 内容 | 备注 |
| --- | --- | --- |
| name（必填） | 需求分析 | 启动任务，无前置 |
| dependencies（必填） | 无 | 转写为空数组 |

任务 2：

| 字段 | 内容 | 备注 |
| --- | --- | --- |
| name（必填） | 技术选型 | 硬依赖需求分析 |
| dependencies（必填） | 需求分析 | 单前置 |

任务 3：

| 字段 | 内容 | 备注 |
| --- | --- | --- |
| name（必填） | 架构设计 | 双前置汇合 |
| dependencies（必填） | 需求分析、技术选型 | 顿号分隔多前置 |

任务 4：

| 字段 | 内容 | 备注 |
| --- | --- | --- |
| name（必填） | 开发实施 | — |
| dependencies（必填） | 架构设计 | — |

> 逐任务一组表格；任务数量按项目计划扩展（典型 8-20 项），每组 2 行字段名与「（必填）」标注保持一致。
