# 安索夫矩阵内外数据融合规范

> 本 Skill 的交叉验证主轴是「外部基准 ↔ 内部数据」：内部数据（工作坊采集的产品 × 市场
> 四象限位置）是分析主体，外部源（World Bank/IMF 宏观指标）仅提供目标市场增长率参照。

## 融合流程

1. **内部数据定基**：工作坊采集的四象限清单（模板 `templates/ansoff_product_market_matrix.md`）
   是安索夫矩阵的骨架——外部数据不改写产品/市场的象限归属
2. **外部印证**：拟进入新市场/新产品对照宏观增长基准——
   - World Bank（宏观指标）：目标市场 GDP 规模/增速（NY.GDP.MKTP.CD / NY.GDP.MKTP.KD.ZG）
     校验市场吸引力的量级
   - IMF（WEO 展望）：NGDP_RPCH 等中期增长展望校验增长预期的可持续性
3. **风险校准**：内部增长预期显著高于宏观基准（2 倍以上）的路径，风险等级上调一档并标注内部依据

## 冲突处理（宏观基准与内部预期矛盾）

| 矛盾类型 | 处置 |
| --- | --- |
| 内部预期增长高于宏观基准 2 倍以上 | 双方并列呈现：保留内部预期 + 标注「超额增长假设」，要求给出份额/客单内部依据 |
| 宏观负增长、内部预期正增长 | 暂停判断：列入工作坊复议清单，多样化路径默认升档风险 |
| 外部指标缺失（小市场无国家码覆盖） | 风险档降档采用保守区间，标注数据缺口（模板缺口登记区记录） |

## 内外结论权重

- **四象限现有位置**（existing/new 产品 × 市场）：内部数据权重 100%（外部源不评判内部归属）
- **增长率基准/风险等级**：内部预期为分析主体，宏观基准用于校准印证（非数值加权——
  安索夫风险等级判定不做加权总分，R2-F8）；矛盾处置按冲突表分级裁决，
  校准结果并列呈现于风险评估依据
- **推荐战略**：以校准后的风险等级为输入，象限选择逻辑不受数据来源影响

## 基准粒度限制声明

World Bank/IMF 宏观指标是**国家维度**而非**行业维度**：
- 适用于：目标市场国别的宏观增长环境校验（进入/不进入的量级论证）
- 不适用于：细分行业增长率基准（行业维度需内部行业研究或行业协会数据补充，登记于缺口区）
- 时效边界：宏观指标 TTL 7 天，跨季度结论需重新采集印证
