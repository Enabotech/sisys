# 安索夫矩阵风险等级评分锚点（低/中/高三档）

> 刻度声明：本 Skill 对四象限增长路径按**风险等级三档刻度**（低/中/高）评估，
> 定档主体为工作坊业务专家（引导者防锚定，见 workshop_guide.md）；
> 定档后经外部增长率基准校准（规则见 data_fusion.md）。

## 分档含义

| 档位 | 判定标准 |
| --- | --- |
| 低 | 现有产品 × 现有市场（市场渗透）：能力与渠道均已验证，风险来自执行而非结构性 |
| 中 | 单边新（市场开发/产品延伸）：产品与市场其一为已有基础，另一侧需新验证（新渠道/新技术） |
| 高 | 双边新（多样化）：产品与市场同时陌生，存在能力与需求双重不确定性 |

## 锚点示例（市场渗透/多样化两端）

- **低档正例**：现有座舱域控制器向已配套车企提升渗透率（渠道/产品双验证）
- **低档反例**：现有产品在同一市场单纯降价冲量（风险低但不构成象限移动——应记入执行预算而非增长路径）

## 锚点示例（市场开发/产品延伸单边新）

- **中档正例**：现有中控显示屏进入东南亚乘用车市场（产品已验证，渠道待建）
- **中档正例**：现有渠道导入软件订阅服务（渠道已验证，商业模式待验证）
- **高档正例**：舱驾一体新平台进入欧洲商用车市场（技术平台与市场双新）
- **中档反例**：现有产品在现有市场加大促销（属市场渗透而非产品延伸——象限归属误判，非风险误判）

## 聚合规则

- 四象限逐路径定档，不做加权总分（安索夫是路径选择地图而非评分卡）
- 增长率校准：目标市场宏观增速（WB/IMF）显著低于内部预期时风险上调一档并标注
- 推荐战略优先级：同收益假设下低风险路径优先；高风险路径必须附超额收益论证
