# 变革准备度/利益相关者影响力评分锚点（1-5 刻度）

> 刻度声明：本 Skill 采用 **1-5 整数刻度**（1 = 极低，5 = 极高），对组织变革准备度与
> 逐个利益相关者的影响力/支持度评分。评分主体为访谈引导者与变革发起人（防锚定，
> 见 workshop_guide.md）。

## 分档含义（影响力 / 准备度通用）

| 分值 | 强度 | 判定标准 |
| --- | --- | --- |
| 5 | 决定性 | 该角色/因素可单独决定变革成败（如 CEO 否决权、全员抵触） |
| 4 | 显著 | 对变革进程有重大影响，需专项策略应对 |
| 3 | 中等 | 明确影响但可被沟通/机制部分化解 |
| 2 | 边际 | 影响有限，仅需纳入常规沟通 |
| 1 | 微弱 | 影响可忽略，仅登记备查 |

## 锚点示例（利益相关者影响力）

- **5 分正例**：职能中台负责人 B——掌握三个试点事业部的编制与预算审批权（反对即卡死赋能环节）
- **3 分正例**：事业部总经理 A——试点成败影响其任期考核，但无跨事业部否决权
- **1 分反例**：外部供应商接口人——仅受变革结果影响，无推动/阻挠能力

## 锚点示例（变革准备度）

- **5 分正例**：上轮变革按期达成且兑现激励——组织对变革承诺有信任存量
- **3 分正例**：高层共识但中层观望（历史上有一轮变革半途回摆）
- **1 分反例**：近两年经历两轮未兑现的重组——紧迫感论证将被「又来了」情绪对冲

## 聚合规则

- 利益相关者矩阵：影响力 ≥4 且反对/观望 → 专项转化策略（沟通计划优先对象）；
  影响力 ≤2 仅常规通报
- 准备度 ≤2 时，Kotter 路径必须在第 1 步（紧迫感）与第 2 步（联盟）加重投入，
  禁止直接进入愿景宣贯
- 阻力强度 1-5 刻度与准备度同向折算：阻力 ≥4 的来源必须进入 risk_mitigation 清单
