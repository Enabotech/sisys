# 变革管理内外数据融合规范

> 本 Skill 的交叉验证主轴是「外部基准 ↔ 内部数据」：访谈采集的变革内容与利益相关者立场
> 是分析主体，外部源（NewsAPI/Tavily）仅提供行业变革趋势与实践情报的印证参照。

## 融合流程

1. **内部数据定基**：利益相关者访谈评估表（模板 `templates/change_stakeholder_assessment.md`）
   确定变革内容、逐人立场/影响力与阻力根因——外部数据不改写内部立场判断（立场以访谈一手
   认知为准）
2. **外部印证**：变革紧迫性与行业趋势判断对照外部基准——
   - NewsAPI（行业变革趋势新闻）：同业转型/组织调整/技术冲击动态，印证紧迫感论证（第 1 步）
   - Tavily（变革实践情报）：行业变革方法论/案例/沟通工具，印证赋能与短期胜利设计（第 5-6 步）
3. **结论校准**：外部证据充分（≥1 源直接印证）时趋势判断与借鉴措施可采纳；仅有内部认知时
   该参照项标注「未经外部印证」并降级为候选建议

## 冲突处理（外部基准与内部认知矛盾）

| 矛盾类型 | 处置 |
| --- | --- |
| 外部显示行业已普遍转型、内部认为尚早 | 外部基准优先：上调紧迫感论证强度，修正前双方并列呈现于依据 |
| 内部判断趋势紧迫、外部无印证 | 双方并列呈现：保留内部判断 + 标注「未经外部印证」，不下结论 |
| 外部案例做法与内部阻力结构相反 | 暂停判断：列入访谈复议清单，以最新一手利益相关者访谈为准修正 |

## 内外结论权重

- **立场/阻力/准备度（内部主体）**：内部数据权重 100%（立场与阻力是访谈事实，外部不评判）
- **行业趋势参照与最佳实践借鉴（外部象限）**：内部认知为分析主体，外部基准用于校准印证
  （非数值加权——变革路线图不做加权总分）；矛盾处置按冲突表分级裁决，
  校准结果并列呈现于路线图依据
- **Kotter 路径裁剪**：以校准后的准备度与矩阵为输入，路径逻辑不受数据来源影响

## 基准粒度限制声明

NewsAPI/Tavily 为新闻与 Web 检索源，其覆盖是**行业事件级**而非**结构化指标级**：
- 适用于：事件性趋势印证（同业转型公告/组织调整新闻/变革案例复盘）
- 不适用于：组织健康度等定量基准（如员工敬业度指数；需定量时结合 bsc-scorecard 的
  learning_growth 链路）
- 时效边界：新闻源 TTL 6h/24h，超过 TTL 的趋势判断需重新采集印证
