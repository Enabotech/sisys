# SPACE 四维度评分锚点（1-7 刻度，SPACE 惯例）

> 刻度声明：本 Skill 按 SPACE 惯例采用 **1-7 整数刻度逐因子打分**：
> FS/IS 取正值（+1 弱 ~ +7 强），CA/ES 取负值（-1 轻微 ~ -7 严重）；
> 维度分 = 因子均分。评分主体为业务专家（问卷 + 访谈，引导者防锚定，见 workshop_guide.md）。

## 分档含义（四维度独立阶梯，替代原「正负换算括注」——原对照表三行混用
镜像与零点对称两套映射规则且 +5 无对应，换算歧义；四维独立打分后不再需要换算）

| 档位 | FS/IS（正向维度） | CA/ES（负向维度） |
| --- | --- | --- |
| ±7 / ±6 | 极强支撑 / 威胁极轻 | 极弱支撑 / 威胁极重 |
| ±5 / ±4 | 较强支撑 / 威胁可控 | 较弱支撑 / 威胁明显 |
| ±3 / ±2 / ±1 | 支撑与制约并存 → 明显制约 | 一般波动 → 环境严峻 |

## 锚点示例（FS 财务实力，内部维度，+1 弱 ~ +7 强）

- **+6 正例**：经营现金流连续 8 季为正，资产负债率 28%，ROE 18%
- **+4 正例**：盈利稳定但资本开支占用高，资产负债率 52%
- **+2 反例**：现金流依赖单一大客户回款（客户集中风险应同时计入 CA 因子，避免重复计分）

## 锚点示例（IS 产业实力，外部维度，+1 弱 ~ +7 强）

- **+6 正例**：行业增速 15%+ 且处于技术迭代红利期（IMF 行业增加值增速校准）
- **+4 正例**：行业增速 5%-8%，需求稳定但产能逐步扩张
- **+2 反例**：仅凭「宏观 GDP 增长」直接推定产业强劲（宏观维度≠行业维度，见 data_fusion.md）

## 锚点示例（CA 竞争优势，内部维度，-1 优势显著 ~ -7 全面劣势）

- **-2 正例**：差异化壁垒稳固（专利族 + 品牌认知），主要竞对绕开成本高
- **-4 正例**：与主要竞对产品同质化明显，靠价格与渠道维持份额
- **-7 反例**：全面劣势/替代威胁严峻——应联动 vrio-framework 评估资源禀赋后再定向

## 锚点示例（ES 环境稳定性，外部维度，-1 稳定 ~ -7 剧变）

- **-2 正例**：CPI 通胀稳定在 2% 附近（WB FP.CPI.TOTL.ZG 校准），政策连续性好
- **-4 正例**：通胀 5%-8% 波动，行业补贴政策处于退坡期
- **-7 反例**：恶性通胀/汇率剧变——超出普通经营假设，应联动 scenario-planning 情景规划

## 聚合规则

- 维度分 = 该维度全部因子分的算术平均（保留一位小数），FS/IS 保持正值、CA/ES 保持负值
- 坐标定向：x = CA + IS（x>0 偏进取/竞争侧，x<0 偏保守/防御侧），y = FS + ES（y>0 偏进取/保守侧，y<0 偏竞争/防御侧）；
  x>0 且 y>0 进取 / x>0 且 y<0 竞争 / x<0 且 y<0 防御 / x<0 且 y>0 保守
- 外部校准：IS/ES 经 WB/IMF 基准换算档位修正（规则见 data_fusion.md）；FS/CA 不受外部数据影响
