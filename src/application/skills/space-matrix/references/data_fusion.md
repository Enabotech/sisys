# SPACE 矩阵内外数据融合规范

> 本 Skill 的交叉验证主轴是「外部基准 ↔ 内部数据」：内部评分（FS 财务实力/CA 竞争优势，
> 问卷 + 专家访谈）是分析主体，外部源（World Bank/IMF 宏观指标）仅支撑 IS/ES 两外部维度的校准。

## 融合流程

1. **内部数据定基**：问卷 + 专家访谈的因子评分（模板 `templates/space_dimension_scoring.md`）
   聚合为四维度分——FS/CA 纯内部维度以工作坊共识为准
2. **外部校准（仅 IS/ES）**：——
   - World Bank（治理/通胀指标）：ES 环境稳定性以 CPI 通胀（FP.CPI.TOTL.ZG）/
     治理效能（CC.EST）换算档位校准
   - IMF（WEO 展望）：IS 产业实力以实际增长展望（NGDP_RPCH）校准需求环境
3. **偏离处置**：IS/ES 内部预评与外部基准换算档位偏离一档以上时，按外部基准修正并标注内部原判

## 冲突处理（外部基准与内部预评矛盾）

| 矛盾类型 | 处置 |
| --- | --- |
| 外部宏观恶化、内部预评乐观（ES 冲突） | 外部基准优先修正：ES 下调，双方并列呈现于定位依据 |
| 外部展望强劲、内部预评保守（IS 冲突） | 双方并列呈现：保守值参与定向，乐观值列入工作坊复议清单 |
| 指标缺失（小市场无国家码覆盖） | 沿用内部预评并标注「未经外部校准」的数据缺口（模板缺口登记区） |

## 内外结论权重

- **FS 财务实力 / CA 竞争优势（内部维度）**：内部数据权重 100%（外部源不评判内部能力）
- **IS 产业实力 / ES 环境稳定性（外部维度）**：外部基准权重 70% / 内部预评 30%——
  宏观基准修正内部预评，修正前双方并列呈现
- **坐标定向**：以校准后四维度分计算（x = CA + IS，y = FS + ES），定向逻辑不受数据来源影响

## 基准粒度限制声明

World Bank/IMF 宏观指标是**国家维度**而非**行业维度**：
- 适用于：宏观环境稳定性（ES）与需求大环境（IS）的国别级校准
- 不适用于：细分行业景气度（IS 的行业修正需内部行业研究补充，登记于缺口区）
- 时效边界：宏观指标 TTL 7 天，跨季度定位需重新采集校准
