# 组织设计五维对齐度评分锚点（1-5 刻度）

> 刻度声明：本 Skill 采用 **1-5 整数刻度**逐条目评维度对齐度——「对齐」指该条目
> 对战略维陈述的支撑程度（条目与战略方向的一致性），非条目自身质量。
> 评分主体为工作坊业务专家（引导者防锚定，见 workshop_guide.md）。

## 分档含义

| 分值 | 对齐强度 | 判定标准 |
| --- | --- | --- |
| 5 | 决定性支撑 | 该条目直接构成战略落地的关键支点，缺失则战略不可行 |
| 4 | 显著支撑 | 明显支撑战略方向，替代方案需要一年以上建设周期 |
| 3 | 中等支撑 | 支撑战略但有缺口或冗余，可经调整补齐 |
| 2 | 边际支撑 | 与战略关联弱或方向部分偏离，特定情景下才起作用 |
| 1 | 失配 | 与战略方向冲突或完全无关（此类条目应进入优化建议而非仅登记） |

## 锚点示例（structure 维——汇报线）

- **4 分正例**：区域总经理向销售副总裁汇报（区域市场扩张战略的关键决策通道，前线有定价权）
- **2 分正例**：采购经理向区域总经理汇报（集中采购战略下区域自采偏离方向）
- **1 分反例**：区域总经理向总部财务总监汇报（汇报线与市场扩张战略完全失配——此类结构应重构）

## 锚点示例（rewards 维——激励政策）

- **4 分正例**：区域利润分享计划（牵引区域总经理对市场份额与利润双目标负责）
- **2 分正例**：全员统一工龄工资（与任何战略无特定关联，属保健因素）
- **1 分反例**：仅考核采购成本节约（与区域市场扩张战略反向激励——区域为省成本牺牲响应速度）

## 聚合规则

- 各维对齐分值 = 维度内全部条目分值的最小值（短板优先，见 framework_logic.md 步骤 6）
- 五维分值写入 design_recommendation.fit_assessment（外层键为维度名）
- 评分纪律：以 strategy.statements 为唯一对齐基准，禁止「看现状打高分」的惰性锚定
