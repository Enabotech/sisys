# PESTEL 六维度评分锚点

> 评分范围 0-1：机会趋 1，威胁趋 0，0.5 为中性。评分必须有采集数据支撑，禁止拍脑袋。

## 分档定义

| 分值区间 | 含义 | 数据特征 |
|---------|------|---------|
| 0.85-1.00 | 强机会 | 多源一致显示显著利好（如 GDP 增速 >6% 且政策明确支持） |
| 0.70-0.85 | 机会 | 主流证据利好，个别指标中性 |
| 0.55-0.70 | 弱机会 | 利好与中性证据混合，利好略占优 |
| 0.45-0.55 | 中性 | 利好/威胁证据均衡，或数据不足以下结论 |
| 0.30-0.45 | 弱威胁 | 威胁证据略占优 |
| 0.15-0.30 | 威胁 | 多源一致显示显著不利（如监管收紧 + 经济下行） |
| 0.00-0.15 | 强威胁 | 全源一致严重不利（如行业禁令、系统性危机） |

## 维度示例锚点

### P 政治
- 0.9：治理指数全球前 20%，目标行业列入国家战略新兴产业目录
- 0.5：政策中性，无明确支持或限制信号
- 0.1：政局动荡或行业面临禁令风险（多源印证）

### E 经济
- 0.9：GDP 增速 >6%、通胀 <2%、行业景气指数上行
- 0.5：GDP 增速 3-4%、通胀温和
- 0.1：衰退信号（连续两季度负增长）+ 高通胀（>10%）

### S 社会
- 0.9：目标客群规模年增 >10%，消费倾向与产品高度匹配
- 0.5：人口结构稳定，消费偏好中性
- 0.1：目标客群快速萎缩或社会接受度显著恶化

### T 技术
- 0.9：R&D 投入占比 >3%，核心技术专利年增 >20%
- 0.5：技术演进平稳
- 0.1：技术路线面临颠覆且自身无布局

### En 环境
- 0.9：行业碳强度显著低于均值，符合 IPCC 1.5°C 路径
- 0.5：环境合规成本可控
- 0.1：面临碳关税/排放限额等重大合规压力

### L 法律
- 0.9：法规明确支持（补贴、税收优惠立法）
- 0.5：法规稳定，合规成本可预期
- 0.1：新法规显著增加合规成本或限制经营
