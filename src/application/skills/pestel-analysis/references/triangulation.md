# PESTEL 多源三角化规范

> 目的：以源级三角化（6 个声明源全部参与采集）为基线，避免单一来源偏差导致战略误判；
> 维度级直接映射源数不足 3 源时须跨维间接印证或显式标注「印证不足」。

## 三角化流程

1. **指标声明**：Think 阶段为每个维度声明 1-3 个关键指标（对齐 `scoring_matrix.json` 的 indicators）
2. **来源映射**：每个指标映射候选来源（6 个声明源中选取，主源 + 印证源——候选来源优先 ≥3；
   维度级直接映射源数以 SKILL.md §5 映射表为准，实际不足时跨维关联印证或在 `sources` 标注缺口）
3. **独立采集**：各来源独立采集（`$DATA_SOURCE` 标记并发执行），禁止互相引用
4. **交叉比对**：
   - 数值型指标：偏差 ≤10% 视为一致；偏差 >10% 触发冲突裁决
   - 事实型指标：多源叙述一致视为印证；叙述矛盾触发冲突裁决
5. **冲突裁决**：
   - 优先级：官方统计（world-bank / imf / eurostat / china-nbs / ipcc）> 新闻舆情（newsapi）
   - 时效优先：同优先级来源取 `source_timestamp` 更新者
   - 裁决过程与理由必须记录在维度 `indicators` 的观测备注中
6. **来源登记**：维度 `sources` 字段如实登记实际印证来源，直接映射不足或印证不足时显式标注数据缺口并下调置信度

## 6 源角色分工

| 来源 | 角色 | 典型印证维度 |
|------|------|-------------|
| world-bank | 官方统计主源 | P（治理）、E（GDP）、S（人口）、T（R&D） |
| imf | 官方统计主源 | E（经济展望、通胀、汇率） |
| eurostat | 区域官方统计 | En（欧盟环境）、L（欧盟法规）、E（欧盟经济） |
| ipcc | 权威专题数据 | En（气候情景、碳排放） |
| newsapi | 时效舆情印证 | P（时政）、L（法规动态）、T（技术新闻） |
| china-nbs | 中国官方统计 | E（中国经济）、S（中国社会）、P（中国政策） |

## 数据源口径边界

- world-bank / imf：国家宏观口径（非行业维度，行业结论须经宏观→行业显式映射）
- eurostat：欧盟口径（region_scope 非 eu 时仅作全球参照，不作主证）
- newsapi：以英文新闻覆盖为主（中文 query 可用但覆盖有限）
- china-nbs：中国行业统计口径
- ipcc：气候科学口径

## 禁止事项

- 禁止用同一来源的不同指标或多个 query（name/#2 键）互相"印证"（伪三角化——独立性以源为单位，同源多 query 不构成独立来源）
- 禁止在 sources 字段中登记未实际采集的来源
- 缓存命中（cache_hit=true）的数据仍计入印证，但必须结合 freshness_score 评估时效性
