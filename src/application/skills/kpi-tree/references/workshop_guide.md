# KPI 树战略解码工作坊引导（2-4 小时结构化）

> 形态说明：本 Skill 的采集形态是**战略解码工作坊**——战略目标逐层解码
> （战略 → 部门 → 个人）+ 数据仓库基线对齐收口。

## 会前准备（T-3 天）

| 时点 | 动作 | 产出 |
| --- | --- | --- |
| T-3 天 | 分发 `templates/kpi_tree_decomposition.md` 与预填指引给各部门负责人 | 各自预填目标草稿（不汇总，防锚定） |
| T-2 天 | 数据仓库按指标口径导出 KPI 现值基线（近 4 季），并与目标草稿对齐指标口径 | 基线导出表 + 口径映射表 |
| T-1 天 | 引导者汇总外部参照速览（官方行业统计标题级 + 同业绩效动态标题级） | 速览页（仅事实，不预定档） |

## 现场流程（2-4 小时）

| 环节 | 时长 | 产出物 |
| --- | --- | --- |
| 开场与规则宣讲 | 15 min | 定档口径与纪律共识（防锚定/防软承诺） |
| 战略层目标陈述与解码 | 40 min | objectives 战略层条目 + 档位候选 |
| 部门层目标逐部门分解 | 40 min | objectives 部门层条目 + 权重分配 |
| 个人层目标抽样校准 | 20 min | objectives 个人层条目（抽样部门全量） |
| 基线与口径对齐 | 30 min | baseline_data 定稿（指标 → 现值/口径） |
| 外部参照定档校准 | 20 min | 定档结论（矛盾项登记复议）+ 分解表定稿 |

## 时间压缩指引（2 小时精简变体）

| 环节（精简版） | 时长 | 说明 |
| --- | --- | --- |
| 开场与规则宣讲 | 15 min | 纪律宣讲不可压缩 |
| 战略层目标陈述与解码 | 30 min | — |
| 部门层目标逐部门分解 | 35 min | 个人层抽样校准并入本环节 |
| 基线与口径对齐 | 25 min | 口径登记不可省 |
| 外部参照定档校准 | 15 min | 仅战略层 KPI 定档校准 |

- **压缩代价**：个人层目标仅抽样，全量分解转会后由 Agent 辅助生成后人工复核
- **不可压缩项**：防锚定/防从众纪律宣讲、基线口径登记、数据缺口登记——省略即失效

## 角色分工

- **引导者**：控流程/控时/执行纪律，不参与内容判断
- **部门负责人**（逐部门参与）：本部门目标分解与定档的提出与答辩主体
- **数据/BI 代表**：基线导出口径解释与指标口径裁定
- **记录员**：实时填写分解表，逐条登记证据来源与数据缺口

## 引导纪律

- **防锚定**：预填草稿开场后才同时公开；禁止以「上年 KPI」为起点修修补补
- **防软承诺**：部门目标加权须支撑战略层档位，缺口当场暴露不许摊薄了事
- **防无支撑激进**：突破档目标必须陈述结构性举措，无举措即降档
- 单指标讨论超 10 分钟即登记「待议」移入缺口登记区，口径对齐环节裁定

## 会后跟进

1. 记录员 24h 内回收定稿分解表，补齐缺口登记区的替代来源
2. 按模板「采集表格」字段构造 `input_schema` 参数：
   `business_objectives.{objectives, baseline_data}`
   （每条目标携带档位与证据来源，供 Agent 融合外部参照时校准定档）
3. 调用本 Skill 执行：Agent 结合外部参照（国家统计局/NewsAPI 双源印证）生成 KPI 定义
4. 结果回传部门负责人确认（重点：目标超出行业趋势的警示项处置与四要素定稿采纳）
