# KPI 树内外数据融合规范

> 本 Skill 的交叉验证主轴是「外部基准 ↔ 内部数据」：目标分解链与 KPI 现值基线
> （战略规划文件 + 数据仓库导出）是分析主体，外部源（国家统计局/NewsAPI）仅提供
> 行业指标统计与绩效动态的参照印证。

## 融合流程

1. **内部数据定基**：目标分解表（模板 `templates/kpi_tree_decomposition.md`）
   是 KPI 树的骨架——目标层级结构与部门归属以内部战略共识为准，
   外部源不新增/不改写内部目标（目标方向以战略解码工作坊共识为准）
2. **外部参照**：逐 KPI 对照外部基准——
   - 国家统计局（官方行业统计）：行业增速/效率类指标为目标值设定提供中国行业
     维度的统计参照
   - NewsAPI（绩效动态）：同业绩效事件与指标实践为目标激进程度提供时效性印证
3. **档位校准**：目标值设定经外部参照印证（≥1 源支持）时档位可上调/下调一档；
   仅有内部判断时档位下调一档并标注「未经行业参照」

## 冲突处理（外部参照与内部判断矛盾）

| 矛盾类型 | 处置 |
| --- | --- |
| 行业增速显著低于内部目标增速 | 官方统计优先：登记「目标超出行业趋势」警示，目标值降档或补强依据 |
| 内部目标激进、外部无参照 | 双方并列呈现：保留内部目标 + 标注「未经行业参照」，不下结论 |
| 新闻绩效事件与官方统计方向相反 | 以官方统计为准（事件为佐证非基准），事件列入口径复议清单 |

## 内外结论权重

- **目标分解结构与指标口径**：内部数据权重 100%（外部源不评判内部目标归属与口径定义）
- **目标值档位**：内部判断为分析主体，官方统计用于校准印证（非数值加权——档位判定
  不做加权总分，R2-F8）；矛盾处置按冲突表分级裁决，校准结果并列呈现于目标值依据
- **KPI 四要素定稿**（口径/目标/权重/监控频率）：以校准后的目标档位为输入，
  定义逻辑不受数据来源影响

## 基准粒度限制声明

china-nbs 是**中国官方行业统计**：其口径是行业维度（如行业营收/产量增速），
不提供「某企业/某部门」级指标数据（企业级目标须经「行业 → 企业」的显式份额/效率
映射并标注假设）。NewsAPI 为新闻检索源，其覆盖是**行业事件级**而非**结构化指标级**：
适用于绩效动态的定性印证，不适用于目标值定量基准。时效边界：china-nbs TTL 24h /
newsapi TTL 6h，超过 TTL 的结论需重新采集参照。
