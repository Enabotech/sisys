# KPI 目标档位锚点（三档刻度）

> 刻度声明：本 Skill 的目标值设定采用**三档刻度**——基准档（行业中位）/ 挑战档
> （行业领先）/ 突破档（超越行业天花板），对战略层 KPI 逐指标定档。
> 定档主体为战略解码工作坊业务负责人（引导者防锚定，见 workshop_guide.md）。

## 分档含义

| 档位 | 含义 | 判定标准 |
| --- | --- | --- |
| 突破档 | 超越行业天花板 | 目标值超行业头部水平，须有结构性举措支撑（产能/技术/渠道突破） |
| 挑战档 | 行业领先 | 目标值达行业前 1/4 分位，须有明确抓手与资源投入 |
| 基准档 | 行业中位 | 目标值对齐行业中位水平，常规经营即可达成 |

## 锚点示例（以营收增速类 KPI 为例）

- **突破档正例**：营收三年翻番——新建产线投产 + 两个海外定点支撑（举措与目标匹配）
- **基准档正例**：营收年增 8%——对齐行业增速中位（官方统计参照）
- **突破档反例**：营收三年翻番但无结构性举措说明（无支撑的拍脑袋目标，档位无效）
- 基线缺失时禁止定档：现值基线（数据仓库导出）是定档前提，缺失即登记缺口

## 目标值换算规则

1. 以 `baseline_data` 现值为基数，按档位乘数换算目标值
   （基准档 ≈ 行业中位增速；挑战档 ≈ 行业前 1/4；突破档须逐一论证）
2. 行业增速基数优先取官方统计（china-nbs 行业维度），新闻动态仅作方向佐证
3. 定量换算须登记口径（含税/不含税、统计范围），口径不同禁止直接比对

## 与 BSC 档位互查映射（R2-F6：两 Skill 互相负向跳转，同名档位判据不同）

两套档位是「常规可达目标」的两种定档依据（本表与 bsc-scorecard scoring_anchors
互查映射表**字面一致**，双向维护）：

| kpi-tree 档位（行业分位口径） | BSC 档位（达成概率口径） | 映射说明 |
| --- | --- | --- |
| —（无对应档） | 保守（≥90% 达成概率） | 低于行业中位的目标不进入 KPI 树分解，BSC 保守档止步于计分卡 |
| 基准（行业中位） | 基准（60%-90% 达成概率） | 同一「常规可达」语义：有官方统计时用分位法，无统计时用概率法 |
| 挑战（行业前 1/4） | 挑战（30%-60% 达成概率） | 有行业分位数据时优先分位法定档 |
| 突破（超行业天花板，逐一论证） | —（无对应档） | 超出 BSC 挑战上限，BSC→kpi-tree 传递时须复议登记 |

> 两 Skill 同用（BSC 定目标 → kpi-tree 分解）时档位冲突取保守侧，并在分解表中登记换算依据。

## 聚合规则

- 分解树自上而下定档：战略层档位 ≥ 部门层档位加权结果（防止下级目标软承诺）
- 同层级权重合计 100%，权重按分解树层级分配（战略层 1.0，部门层按贡献拆分）
- 监控频率按影响速度匹配：日（产线级）/ 周（运营级）/ 月（部门级）/ 季（战略级）/ 年（长周期）
- 定档后档位变化超过一档的，须在目标值依据中登记参照来源
