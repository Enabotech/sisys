# KPI 树目标分解表

> 战略解码工作坊现场填写；采集字段与 SKILL.md `input_schema` 一一对应
> （business_objectives 为嵌套分区，分区内字段即 Schema 叶子键，objectives 为
> array 逐条一行形态）。定档标准见 `references/scoring_anchors.md`。

## 基本信息

| 字段 | 说明 |
| --- | --- |
| 分析对象 | 目标企业/事业部名称 |
| 战略周期 | 如 2027 年度 / 2026-2030 |
| 工作坊日期 | 填写日期 |
| 引导者/记录员 | 名字 |
| 基线取数口径 | 数据仓库导出期间与口径说明 |

## 采集表格

### business_objectives

> 目标分解链逐条一行（战略 → 部门 → 个人，每行一条目标），下行示例可替换。

| 字段 | 目标档位与描述 | 证据来源 |
| --- | --- | --- |
| objectives（必填） | 突破档 —— 战略：2027 年动力电池业务营收翻番（新建产线 + 两个海外定点支撑） | 战略规划文件 |
| objectives（必填） | 挑战档 —— 部门（销售部）：新签车企定点 12 家 | 销售漏斗复盘 |
| objectives（必填） | 挑战档 —— 部门（制造部）：直通率提升至 92% | 生产月报 |
| objectives（必填） | 基准档 —— 个人：电芯产线组长化成分容批次合格率 95% | 质量台账 |

> KPI 现值基线逐指标一行（数据仓库导出对齐）。

| 字段 | 现值与口径 | 证据来源 |
| --- | --- | --- |
| baseline_data（必填） | 营收：18.5 亿元（含税营业收入口径） | 数据仓库导出 2026-Q2 |
| baseline_data（必填） | 直通率：85%（一次合格率口径） | 数据仓库导出 2026-Q2 |

## 评分锚点

目标档位刻度（基准/挑战/突破）与每档判定标准、正反例锚点见 `references/scoring_anchors.md`；
外部参照后的定档校准规则见 `references/data_fusion.md`。

## 数据缺口登记

| 字段 | 缺口描述 | 替代来源 |
| --- | --- | --- |
| baseline_data | 海外定点收入口径未定（离岸/到岸） | 财务口径对齐会决议 / 管理报表 |
| objectives | 行业增速中位数据缺口（官方统计为行业维度） | 国家统计局行业统计映射 / 行业协会报告 |
