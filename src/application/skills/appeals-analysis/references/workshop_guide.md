# $APPEALS 工作坊引导方法论

> 面向战略研讨场景的 $APPEALS 八维度工作坊引导手册。数据驱动的八维度评分结果
> 是工作坊的输入，工作坊的使命是把评分转化为价值定位决策。

## 1. 工作坊定位

- **时机**：SP/BP 制定期的产品价值定位环节，建议 0.5-1 天
- **前置条件**：本 Skill 已产出基于真实数据的八维度评估（appeals_dimensions + overall_score）
- **产出物**：八维度共识评分表、差距清单（期望 vs 现状）、价值定位优先级排序

## 2. 角色分工

| 角色 | 职责 |
|------|------|
| 引导师 | 控制流程与时间，裁决评分分歧，守护「证据优先」原则 |
| 产品负责人 | 陈述现状八维度表现，回答质询 |
| 市场/销售代表 | 补充一线顾客声音，校验数据证据与体感一致性 |
| 记录员 | 实时登记共识评分、分歧点与行动项 |

## 3. 研讨流程

1. **数据校准（30 分钟）**：宣讲八维度评估结果与溯源证据，确认数据可信度；
   对标注了数据缺口/置信度下调的维度，明确补充验证责任人与时限
2. **期望锚定（60 分钟）**：按 `templates/appeals_customer_questionnaire.md` 的
   八维度问题清单，逐维度研讨目标客群的期望值（而非本企业现状）
3. **差距分析（60 分钟）**：逐维度对比「顾客期望 vs 数据评分」，差距 >0.3 的
   维度列入差距清单；对照 `references/scoring_anchors.md` 复核分档合理性
4. **优先级排序（45 分钟）**：按「客群重要性 × 差距幅度」二维排序，锁定
   Top 3 改进维度与 Top 2 强化维度（优势巩固）
5. **行动闭环（30 分钟）**：每个锁定维度明确 Owner、里程碑与验证指标，
   接入 BP 关键任务

## 4. 引导纪律

- 任何评分调整必须援引采集证据或一线顾客事实，禁止「我觉得」式拍分
- 分歧无法弥合时记录双方证据与评分，不强制平均
- 数据缺口维度禁止在工作坊内补齐结论，只登记验证行动

## 5. 与其他工具的衔接

- 上游：pestel-analysis（宏观环境输入客群结构变化趋势）
- 下游：value-curve-analysis / value-proposition-canvas（八维度结论转化为价值曲线与主张）
