# $APPEALS 八维度评分锚点（0-1）

> 每维度评分 0-1：1 = 顾客价值主张完全契合目标客群期望（优势），0 = 严重背离（劣势）。
> 评分必须基于采集证据，对照锚点分档，禁止凭空给分。`overall_score` 为八维度等权均值。

## 通用分档

| 区间 | 语义 |
|------|------|
| 0.8-1.0 | 显著优势：证据显示顾客高度认可，口碑/数据一致向好 |
| 0.6-0.8 | 相对优势：多数证据正面，存在局部痛点 |
| 0.4-0.6 | 中性：正负证据大体均衡，无明确方向 |
| 0.2-0.4 | 相对劣势：多数证据负面，存在系统性不满 |
| 0.0-0.2 | 显著劣势：证据显示顾客强烈排斥或彻底无感知 |

## 分维度锚点示例

### $ 价格
- 1.0 示例：目标客群主流讨论认为「物有所值」，实际成交价落在客群期望价格带中枢
- 0.5 示例：价格带与客群期望基本对齐，但促销依赖度高、正价购买意愿弱
- 0.0 示例：舆情普遍「定价脱离目标客群」，china-nbs 消费支出结构显示该品类支出占比持续萎缩

### A 可获得性
- 1.0 示例：目标客群常用渠道全覆盖，缺货率近零，购买路径 ≤2 步
- 0.5 示例：线上可得但目标客群偏好的线下触点缺失
- 0.0 示例：目标区域无有效渠道覆盖，顾客讨论频繁出现「买不到」

### P 包装
- 1.0 示例：开箱体验成为自发传播点，环保包装契合客群价值观
- 0.5 示例：包装无功无过，顾客讨论中极少被提及
- 0.0 示例：包装成为负面口碑焦点（过度包装/廉价感/破损率高）

### P 性能
- 1.0 示例：核心功能满意度评测与顾客讨论一致领先竞品
- 0.5 示例：核心功能达标，但存在明确痛点清单（如续航/精度抱怨）
- 0.0 示例：核心功能被证据显示不可靠，退货/投诉集中于此

### E 易用性
- 1.0 示例：目标客群「开箱即用」，学习成本讨论近零
- 0.5 示例：基础操作顺畅，进阶功能学习曲线陡峭
- 0.0 示例：顾客讨论高频出现「不会用/太复杂」，客服咨询集中于操作问题

### A 保证程度
- 1.0 示例：质保政策超越客群期望，售后满意度舆情一致正面
- 0.5 示例：质保达标但售后响应速度存在分化评价
- 0.0 示例：售后舆情负面主导，「维权难」成为品类关联词

### L 生命周期成本
- 1.0 示例：TCO 讨论显示使用/维护成本显著低于客群心理账户
- 0.5 示例：购置成本合理但耗材/维护成本感知偏高
- 0.0 示例：顾客普遍认为「买得起用不起」，置换成本构成流失主因

### S 社会接受度
- 1.0 示例：产品与主流社会价值观/潮流高度契合，使用自带社交认同
- 0.5 示例：社会评价中性，无显著认同也无争议
- 0.0 示例：存在环保/伦理争议舆情，目标客群担心使用引发负面社会评价
