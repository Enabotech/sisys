# 战略地图工作坊引导（2-4 小时结构化）

> 纯内部框架型工作坊：无外部数据采集环节，以管理层结构化输入工作坊替代——
> 因果假设基于管理层的战略判断现场对齐。

## 会前准备（T-3 天）

| 时点 | 动作 | 产出 |
| --- | --- | --- |
| T-3 天 | 分发 `templates/strategy_map_causal_links.md` 与预填指引给业务专家 | 各自预填草稿（不汇总，防锚定） |
| T-2 天 | 收集四维度指标台账（财务报表/客户调研/流程绩效/人才盘点） | 指标素材清单 |
| T-1 天 | 引导者汇总四维度指标速览（标题级，不预判因果） | 速览页 |

## 现场流程（2-4 小时）

| 环节 | 时长 | 产出物 |
| --- | --- | --- |
| 开场与规则宣讲 | 15 min | 纪律共识（防锚定/防从众/方向规范） |
| learning_growth 维度指标评审 | 25 min | learning_growth 指标清单 |
| internal_process 维度指标评审 | 25 min | internal_process 指标清单 |
| customer 维度指标评审 | 25 min | customer 指标清单 |
| financial 维度指标评审 | 25 min | financial 指标清单 |
| 因果假设表述（自下而上） | 40 min | causal_relationships 清单（含 warning 级待澄清项） |
| 因果链闭合检查与主题卡设计 | 30 min | 2-4 张战略主题卡 + 模板定稿 |

## 时间压缩指引（2 小时精简变体）

| 环节（精简版） | 时长 | 说明 |
| --- | --- | --- |
| 开场与规则宣讲 | 15 min | 纪律宣讲不可压缩 |
| 四维度指标连续评审 | 50 min | 每维度条目上限 3 条，指标陈述带现状量级 |
| 因果假设表述 | 35 min | 仅标准方向箭头（自下而上），逆向项移入缺口登记 |
| 闭合检查与主题卡 | 20 min | 仅归纳 2 张主题卡 |

- **压缩代价**：因果假设覆盖面下降，逆向/同层箭头待澄清项转入缺口登记区会后复议
- **不可压缩项**：方向规范宣讲（Kaplan-Norton 自下而上）、warning 级待澄清登记——省略即失效

## 角色分工

- **引导者**：控流程/控时/执行纪律（方向规范与 warning 登记），不参与内容判断
- **业务专家**（2-4 人，覆盖四维度职能）：指标提出与因果假设表述主体
- **记录员**：实时填写模板表格，逐条登记指标量级与待澄清假设

## 引导纪律

- **防锚定**：预填草稿开场后才同时公开；四维度按自下而上序评审（防从财务目标反推因果）
- **防从众**：因果假设先独立写卡后讨论收敛；职级不参与假设成立性权重
- **防溢出**：单条因果假设讨论超 5 分钟即登记「待议」移入缺口登记区
- 每条指标与因果假设必须落到模板行（字段/内容/证据三列齐全才算完成）

## 会后跟进

1. 记录员 24h 内回收定稿模板，补齐缺口登记区的替代来源与 warning 项复议结论
2. 按模板「采集表格」字段构造 `ToolCall.arguments` 参数（模板→arguments 构造闭环）：
   `bsc_indicators.{financial, customer, internal_process, learning_growth, causal_relationships}`
   （指标带现状量级、因果箭头按「原因维度 → 结果维度：假设描述」书写，供 Agent 解析因果链）
3. 调用本 Skill 执行：Agent 基于框架逻辑生成 strategy_visualization
   （nodes / causal_arrows / theme_cards——定性因果链图）
4. 结果回传业务专家确认（重点：warning 级待澄清假设的复议结论；量化验证移交 bsc-scorecard）
