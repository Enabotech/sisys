# VRIO 逐资源核查表

> 内部审计 + 高管访谈现场填写；采集字段与 SKILL.md `input_schema` 一一对应（资源清单为
> array 展开形态，分区标题用顶层键名 resources，分区内字段即 Schema 叶子键——name 与
> vrio_scores 展开的 V-R-I-O 四维）。判定刻度见 `references/scoring_anchors.md`。

## 基本信息

| 字段 | 说明 |
| --- | --- |
| 审计对象 | 目标企业/业务单元名称 |
| 审计期间 | 如 2026-2030 战略周期 |
| 审计/访谈日期 | 填写日期 |
| 引导者（审计组长）/记录员 | 名字 |

## 采集表格

### resources

逐资源一组 5 行（资源名称 + V-R-I-O 四维判定，0-1 刻度）。

资源 1：

| 字段 | 内容与判定（0-1） | 证据来源 |
| --- | --- | --- |
| name（必填） | 固态电池电解质专利族 | 专利盘点表 2026-Q2 |
| value（必填） | 1 —— 直接支撑高能量密度路线，抓住电动化机会 | 技术路线图评审 |
| rarity（必填） | 1 —— 行业同类专利族持有者 3 家（待专利密度外部印证） | 外部基准印证 |
| imitability（必填） | 1 —— 含 3 项独占许可 + 工艺隐性知识，绕开成本极高 | 法务意见书 |
| organization（必填） | 1 —— 量产专项组织与专项激励已落地（高管访谈确认） | 组织架构文件 |

资源 2：

| 字段 | 内容与判定（0-1） | 证据来源 |
| --- | --- | --- |
| name（必填） | 中层项目经理梯队 | 人才盘点表 |
| value（必填） | 1 —— 交付节奏与跨部门协同的必要条件 | PMO 复盘 |
| rarity（必填） | 0 —— 行业普遍具备（外部能力情报印证） | 外部基准印证 |
| imitability（必填） | 0 —— 可通过招聘/咨询在 1 年内获取 | 招聘市场观察 |
| organization（必填） | 1 —— 项目制授权与考核已落地 | 制度文件 |

> 逐资源一组表格；资源数量按审计清单扩展（5-10 项），每组 5 行字段名与「（必填）」标注保持一致。
