# VRIO 内外数据融合规范

> 本 Skill 的交叉验证主轴是「外部基准 ↔ 内部数据」：内部审计 + 高管访谈的 V-R-I-O 判定是
> 分析主体，外部源（USPTO/Tavily）仅提供稀缺性/可模仿性的行业印证参照。

## 融合流程

1. **内部数据定基**：逐资源核查表（模板 `templates/vrio_resources_checklist.md`）经内部审计
   （V/O 两维）+ 高管访谈（O 维校准）形成初步判定——外部数据不改写 V/O 判定（价值与组织
   利用是内部事实）
2. **外部印证**：R/I 两维逐项对照外部基准——
   - USPTO（专利密度）：资源相关技术方向的专利族数量/分布密度，印证稀缺性（行业持有者
     是否 <5 家）与可模仿性（专利壁垒/绕开成本）
   - Tavily（能力情报）：竞对能力建设动向（扩产/人才引进/联合研发），印证能力类资源的
     稀缺性与获取难度
3. **判定校准**：外部证据充分（≥1 源直接印证）时 R/I 判定维持或上调；与内部判断矛盾时按
   冲突处理表处置，修正前双方并列呈现

## 冲突处理（外部基准与内部认知矛盾）

| 矛盾类型 | 处置 |
| --- | --- |
| 专利密度显示行业持有者多于内部判断 | 外部基准优先：R 下调并标注修正依据，修正前双方并列呈现 |
| 内部判 R=1（稀缺）、外部无印证 | 双方并列呈现：保留内部判定 + 标注「未经外部印证」，不下结论 |
| 外部情报与高管访谈方向相反 | 暂停判断：列入审计复议清单，以最新一手审计/访谈为准修正 |

## 内外结论权重

- **V/O 两维（内部事实）**：内部数据权重 100%（价值判断与组织利用以内部审计 + 访谈为准）
- **R/I 两维（行业相对判定）**：内部认知为分析主体，外部基准用于校准印证（非数值加权——
  VRIO 判定链不做加权总分）；矛盾处置按冲突表分级裁决，校准结果并列呈现于分类依据
- **判定链分类**：以校准后的四维判定为输入，分类逻辑（五类判定链）不受数据来源影响

## 基准粒度限制声明

USPTO 为专利检索源、Tavily 为 Web 检索源，其覆盖是**文献级/事件级**而非**结构化指标级**：
- 适用于：稀缺性/可模仿性的密度参照（专利族计数/持有者分布/竞对能力事件）
- 不适用于：资源经济价值的定量判定（V 维不采外部定量；需财务量化时结合 bsc-scorecard 链路）
- 时效边界：专利源 TTL 30 天、Web 源 TTL 24h；超过 TTL 的 R/I 印证需重新采集
