# VRIO 内部审计 + 高管访谈引导（2-4 小时结构化）

> 本 Skill 采集形态是「内部审计 + 高管访谈」而非传统集中工作坊：审计组逐资源核查 V-R-I-O，
> 高管访谈校准 O 维并确认资源清单边界。

## 会前准备（T-3 天）

| 时点 | 动作 | 产出 |
| --- | --- | --- |
| T-3 天 | 分发 `templates/vrio_resources_checklist.md` 与审计底稿指引给资源归口部门 | 各自预填草稿（不汇总，防锚定） |
| T-2 天 | 收集内部数据材料：专利/资产盘点表、组织架构与激励文件、上期能力复盘 | 材料清单 + 高管访谈预约 |
| T-1 天 | 引导者汇总行业专利与能力动态速览（公开标题级，不预判 R/I） | 速览页（仅标题，不预判） |

## 现场流程（2-4 小时）

| 环节 | 时长 | 产出物 |
| --- | --- | --- |
| 开场与规则宣讲 | 15 min | 纪律共识（防锚定/防从众） |
| 资源/能力清单盘点定稿 | 30 min | resources 清单（5-10 项，覆盖有形/无形/能力三类） |
| 逐资源 V 维审计评审 | 40 min | value 判定 + 依据 |
| 逐资源 R/I 维审计评审（对照外部速览） | 40 min | rarity/imitability 判定 + 待印证标注 |
| 高管访谈：O 维校准与清单边界确认 | 40 min | organization 判定 + 清单增删裁定 |
| 判定链汇总与缺口登记 | 20 min | 模板定稿（含判定/证据/缺口登记） |

## 时间压缩指引（2 小时精简变体）

| 环节（精简版） | 时长 | 说明 |
| --- | --- | --- |
| 开场与规则宣讲 | 15 min | 纪律宣讲不可压缩 |
| 资源/能力清单盘点定稿 | 20 min | 清单上限 8 项（战略关联度优先） |
| 逐资源 V 维审计评审 | 25 min | 快评制（每资源 3 min） |
| 逐资源 R/I 维审计评审 | 30 min | 外部对照仅速览行业数据 |
| 高管访谈：O 维校准 | 20 min | 仅校准 O=0.5 边缘资源 |
| 判定链汇总与缺口登记 | 10 min | — |

- **压缩代价**：资源覆盖面收窄，被裁资源转入数据缺口登记区会后补采
- **不可压缩项**：防锚定/防从众纪律宣讲、证据来源登记、数据缺口登记——省略即失效

## 角色分工

- **引导者**（审计组长）：控流程/控时/执行纪律，不参与内容判断
- **业务归口专家**（2-4 人，按资源条线）：V/R/I 判定的证据提供主体
- **高管受访者**（1-2 人）：O 维最终裁判与资源清单边界裁定
- **记录员**：实时填写核查表，逐条登记证据来源与数据缺口

## 引导纪律

- **防锚定**：预填草稿开场后才同时公开；禁止以「上年资源清单」为起点修修补补
- **防从众**：R/I 判定先独立举牌后讨论收敛；职级不参与判定权重（高管仅裁 O 维）
- **防溢出**：单资源讨论超 5 分钟即登记「待议」移入缺口登记区
- 每项资源必须落到核查表行（name + 四维判定 + 证据来源齐全才算完成）

## 会后跟进

1. 记录员 24h 内回收定稿核查表，补齐缺口登记区的替代来源
2. 按模板「采集表格」字段构造 `input_schema` 参数：
   `resources[].{name, vrio_scores.{value, rarity, imitability, organization}}`
   （逐资源携带判定依据与证据来源，供 Agent 融合外部基准时校准 R/I）
3. 调用本 Skill 执行：Agent 结合外部基准（USPTO + EPO OPS 专利双库密度 + Tavily 能力情报）完成判定链分类
4. 结果回传高管确认（重点：R/I 外部印证与内部判定的矛盾项处置、未实现潜在优势的补齐建议）
