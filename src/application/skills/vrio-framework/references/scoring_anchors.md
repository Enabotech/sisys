# V/R/I/O 判定锚点（0-1 刻度）

> 刻度声明：本 Skill 采用 **0-1 刻度**（支持 0 / 0.5 / 1 三档：0 = 否，0.5 = 边缘倾向是，
> 1 = 是）。注意方向：imitability 分值越高 = 模仿难度越大（可防御性越强）。
> 判定主体为内部审计组与高管受访者（引导者防锚定，见 workshop_guide.md）。

## 分档含义

| 维度 | 1 | 0.5 | 0 |
| --- | --- | --- | --- |
| value（价值性） | 直接抓住机会/化解威胁 | 间接/部分贡献 | 与机会威胁无关联 |
| rarity（稀缺性） | 行业持有者 <5 家（外部印证） | 行业少数派但无印证 | 行业普遍具备 |
| imitability（可模仿性） | 专利/隐性知识壁垒，复制成本极高 | 可在 2-3 年内复制 | 可通过市场快速获取 |
| organization（组织利用） | 结构/流程/激励已配套利用 | 部分配套，需补齐 | 组织不支持或未利用 |

## 锚点示例

- **V=1 正例**：固态电池电解质专利族——直接支撑高能量密度路线（抓住电动化机会）
- **V=0 反例**：年报排版专业——与机会/威胁无因果关联（此类条目不应进入资源清单）
- **R=1 正例**：行业同类专利族持有者 3 家（USPTO 检索印证）
- **R=0 正例**：中层项目经理梯队——行业普遍具备（外部情报印证）
- **I=1 正例**：含 3 项独占许可 + 工艺隐性知识，竞对绕开成本极高
- **I=0 正例**：标准 ERP 系统——可采购获取，无防御性
- **O=1 正例**：量产专项组织 + 专项激励已落地（高管访谈确认）
- **O=0 反例**：顶级算法团队但无产品化通道（有资源无利用——未实现潜在优势）

## 判定链聚合规则

判定链重写为经典二叉树逐级下探（全组合闭合——原五条规则在 {0, 0.5, 1}⁴ 空间存在
无规则命中的悬空组合，且 O=0.5 可被判「持续优势」与组织维度定义矛盾）：

1. V=0 → **竞争劣势**（与机会/威胁无关联的资源不进入优势判定）
2. V≥0.5 且 R=0 → **竞争均势**（有价值但不稀缺）
3. R≥0.5 且 I=0 → **暂时竞争优势**（稀缺但可模仿——窗口期优势）
4. I≥0.5 且 O=0 → **未实现潜在优势**（组织未利用是首要行动项）
5. 四维均 ≥0.5：仅 **V=R=I=O 全为 1** → **持续竞争优势**；其余组合
   （R/I/O 任一为 0.5）→ **暂时竞争优势** + 登记边缘判定原因与补齐路径
   （O=0.5 = 组织部分配套——按 Barney 原意未完全利用不可判持续优势，上限暂时优势）

> 0.5 档计入「满足」侧（可进入下一级判定）但须在依据中登记边缘判定原因；
> 判定链自上而下首条命中即定类，输出五分类：竞争劣势 / 竞争均势 / 暂时竞争优势 /
> 未实现潜在优势 / 持续竞争优势。
