# 竞品对标矩阵评分锚点

> 评分范围 0-1：竞品竞争力强趋 1，弱趋 0，0.5 为与自身相当。评分必须有采集数据支撑，禁止拍脑袋。

## 分档定义

| 分值区间 | 含义 | 数据特征 |
|---------|------|---------|
| 0.85-1.00 | 显著领先 | 多源一致显示竞品在该维度显著占优（如份额 >30% 且持续扩张） |
| 0.70-0.85 | 领先 | 主流证据显示竞品占优，个别指标中性 |
| 0.55-0.70 | 略占优 | 占优与中性证据混合，竞品略领先 |
| 0.45-0.55 | 相当 | 竞品与自身实力均衡，或数据不足以下结论 |
| 0.30-0.45 | 略落后 | 落后证据略占优 |
| 0.15-0.30 | 落后 | 多源一致显示竞品显著落后（如份额持续萎缩 + 专利停滞） |
| 0.00-0.15 | 显著落后 | 全源一致显示竞品边缘化（如退出市场信号） |

## 维度示例锚点

### 战略动向
- 0.9：竞品发布明确扩张战略且多源印证落地动作（并购/建厂/高管公开承诺）
- 0.5：战略延续，无显著进攻或收缩信号
- 0.1：竞品战略收缩、剥离相关业务（多源印证）

### 专利布局
- 0.9：竞品核心领域专利申请年增 >20%，高被引专利占比显著高于行业均值
- 0.5：专利申请平稳，技术领域分布与自身重合度中等
- 0.1：专利申请连续下滑或核心专利即将到期且无接续布局

### 产品组合
- 0.9：产品线全价格带覆盖 + 新品迭代周期 <12 个月 + 旗舰产品口碑领先
- 0.5：产品结构稳定，迭代节奏与行业均值相当
- 0.1：产品线老化、新品失败率高、关键市场缺位

### 市场份额
- 0.9：份额 >30% 且连续 4 个季度扩张（china-nbs/行业报道多源印证）
- 0.5：份额稳定在行业均值附近
- 0.1：份额 <5% 且持续萎缩

## 矩阵聚合

各维度评分填入 `templates/competitor_benchmark_matrix.md`（维度 × 企业），
工作坊合议后可按业务重点设定维度权重计算加权竞争力指数；权重与理由必须记录在矩阵备注中。
