# 竞品调研工作坊引导方法论

> 适用：战略团队 2-4 小时竞品对标研讨工作坊。本工具输出作为工作坊的数据输入，
> 工作坊产出作为 SP 市场洞察阶段的竞争格局共识结论。

## 会前准备（T-3 天）

1. 明确议题：行业 / 竞品清单 / 对标维度三要素（对齐 input_schema 必填字段）
2. 运行本工具完成数据采集与初评（产出竞品画像 + 对标矩阵初稿 + 溯源元数据）
3. 将 `templates/competitor_benchmark_matrix.md` 打印/投屏，预填工具采集的指标观测值与初评分数

## 工作坊流程（120-240 分钟）

| 阶段 | 时长 | 活动 | 产出 |
|------|------|------|------|
| 1. 开场 | 10' | 引导师说明议题、规则、产出物 | 议程共识 |
| 2. 数据回顾 | 30' | 逐竞品展示画像与采集依据（含 freshness/confidence） | 数据共识 |
| 3. 分组研讨 | 60' | 按对标维度分组挑战评分：证据是否充分？三角化是否成立？ | 评分调整记录 |
| 4. 全体合议 | 40' | 逐维度 × 逐竞品确认最终评分，记录分歧与裁决理由 | 对标矩阵共识版 |
| 5. 启示提炼 | 30' | 识别自身差距 Top3 与差异化机会 Top3 | 竞争启示清单 |
| 6. 收尾 | 10' | 确认后续行动（输入 SWOT-TOWS / 战略地图） | 行动项 |

## 角色分工

- **引导师**：控场、确保数据驱动讨论（禁止无数据支撑的纯观点）
- **记录员**：填写对标矩阵模板，登记评分调整与理由
- **维度 Owner**：每组 1 人，负责该维度证据陈述（专利维度须能讲清 uspto 信号口径）
- **挑战者**：专职质疑三角化充分性（"这个结论有几个独立来源？"）

## 引导话术

- 评分争议时：「我们回到数据——这家竞品在该维度的 3 个来源分别显示了什么？」
- 数据缺口时：「该竞品缺 X 源印证，我们是标注置信度下调，还是会后补采？」
- 专利维度冷场时：「竞品近 3 年专利申请趋势向上还是向下？技术领域集中在哪？」
- 超时预警：「当前竞品还剩 5 分钟，请聚焦评分与关键证据」

## 会后跟进

- 共识版对标矩阵归档，与工具初稿差异登记调整理由
- 数据缺口登记到数据源治理清单（评估是否需新增适配器或人工补采）
- 竞争启示清单输入 SWOT-TOWS（O/T 象限）与战略地图（客户维度）
