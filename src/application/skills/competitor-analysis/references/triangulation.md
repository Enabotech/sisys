# 竞品情报多源三角化规范

> 目的：确保每个对标维度的关键指标由 ≥3 个独立来源印证，避免单一来源偏差导致竞争误判。

## 三角化流程

1. **指标声明**：Think 阶段为每个对标维度（战略动向/专利布局/产品组合/市场份额）声明 1-3 个关键指标
2. **来源映射**：每个指标映射 ≥3 个候选来源（4 个声明源中选取，主源 + 印证源）
3. **独立采集**：各来源独立采集（`$DATA_SOURCE` 标记并发执行），禁止互相引用
4. **交叉比对**：
   - 数值型指标（份额、专利数）：偏差 ≤10% 视为一致；偏差 >10% 触发冲突裁决
   - 事实型指标（战略发布、产品动态）：多源叙述一致视为印证；叙述矛盾触发冲突裁决
5. **冲突裁决**：
   - 优先级：官方统计/专利库（china-nbs / uspto）> 检索情报（tavily）> 新闻舆情（newsapi）
   - 时效优先：同优先级来源取 `source_timestamp` 更新者
   - 裁决过程与理由必须记录在竞品画像 `strategy_summary` 的观测备注中
6. **来源登记**：竞品 `sources` 字段如实登记实际印证来源（≥3），不足 3 源时显式标注数据缺口

## 4 源角色分工

| 来源 | 角色 | 典型印证维度 |
|------|------|-------------|
| newsapi | 时效舆情印证 | 战略动向（时政/并购/高管言论）、市场份额（行业报道） |
| uspto | 专利技术信号主源 | 专利布局（申请趋势/技术领域分布/核心专利） |
| tavily | Web 情报主源 | 产品组合（官网/评测/定价）、战略动向（深度检索） |
| china-nbs | 中国官方统计 | 市场份额（产销量/行业排名）、中国行业对标 |

## 禁止事项

- 禁止用同一来源的不同指标互相"印证"（伪三角化）
- 禁止在 sources 字段中登记未实际采集的来源
- 缓存命中（cache_hit=true）的数据仍计入印证，但必须结合 freshness_score 评估时效性
- 专利结论仅以 uspto 单源成立时，必须标注"专利维度未三角化"并下调置信度
