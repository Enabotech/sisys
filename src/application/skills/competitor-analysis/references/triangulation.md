# 竞品情报多源三角化规范

> 目的：确保对标结论经多源印证，避免单一来源偏差导致竞争误判。三角化为**源级**语义——
> 7 个声明源全部参与采集（并发覆盖）；维度级直接映射源数以 SKILL.md §5 映射表为准
> （战略动向/产品组合 2 源，专利布局 3 库（uspto+google-patents+epo-ops——域内一致性互证），市场份额 3 源）。

## 三角化流程

1. **指标声明**：Think 阶段为每个对标维度（战略动向/专利布局/产品组合/市场份额）声明 1-3 个关键指标
2. **来源映射**：每个指标映射其全部候选来源（7 个声明源中按 §5 维度映射选取——直接映射源数不足 3 时，以跨维度关联印证补足）
3. **独立采集**：各来源独立采集（`$DATA_SOURCE` 标记并发执行），禁止互相引用
4. **交叉比对**：
   - 数值型指标（份额、专利数、营收）：偏差 ≤10% 视为一致；偏差 >10% 触发冲突裁决
   - 事实型指标（战略发布、产品动态）：多源叙述一致视为印证；叙述矛盾触发冲突裁决
5. **冲突裁决**：
   - 优先级：官方统计/法定披露/专利库（china-nbs / sec-edgar / uspto / google-patents / epo-ops）> 检索情报（tavily）> 新闻舆情（newsapi）
   - 时效优先：同优先级来源取 `source_timestamp` 更新者
   - 裁决过程与理由必须记录在竞品画像 `strategy_summary` 的观测备注中
6. **来源登记**：竞品 `sources` 字段如实登记实际印证来源；直接映射源数不足或印证不足时显式标注数据缺口并下调置信度

## 7 源角色分工

| 来源 | 角色 | 典型印证维度 |
|------|------|-------------|
| newsapi | 时效舆情印证 | 战略动向（时政/并购/高管言论）、市场份额（行业报道） |
| uspto | 专利技术信号库（US 口径） | 专利布局（申请趋势/技术领域分布/核心专利）——美国专利口径，标题软归因 |
| google-patents | 专利技术信号库（全球含 CN 口径） | 专利布局（BigQuery 公共数据集——CN 覆盖 99.96%，assignee 精确聚合；月度更新新鲜度较低） |
| epo-ops | 专利技术信号库（EP 口径） | 专利布局（`pa=` 申请人结构化检索——中文企业名直接归因，与 uspto 双库互证） |
| sec-edgar | 美股法定披露 | 市场份额（10-K 全文 + XBRL 营收时序——美股上市竞品企业级印证） |
| tavily | Web 情报主源 | 产品组合（官网/评测/定价）、战略动向（深度检索） |
| china-nbs | 中国官方统计 | 市场份额（行业总量对标——宏观口径，非企业级份额）、中国行业对标 |

## 数据源口径边界

- **uspto**：仅美国专利口径（不含 CNIPA/WIPO——全球布局画像系统性偏低样本，中国竞品尤甚）；检索为 patent_title 标题关键词匹配（非申请人结构化检索——归因经返回的 assignees 字段研判）
- **google-patents**：BigQuery 公共数据集全球书目口径（CN 覆盖 99.96% SSRN 实证、assignee 精确聚合——月度更新新鲜度较低，趋势结论宜结合源时效评估；月配额 1TiB 扫描字节，耗尽按限流行降级并回落可用库）
- **epo-ops**：EPO 欧洲专利口径（`pa=` 申请人结构化检索支持中文企业名，100+ 专利局含 CN——仅 EP 申请视角；合并后仍缺 CNIPA 本土实时口径（google-patents 补 CN 全景），按「US+全球+EP 三口径」标注）；周配额 4GB/周，耗尽时回落可用库并标注
- **sec-edgar**：仅美股上市公司（非上市/非美竞品无数据）；XBRL 模式字段形态为 concept/unit/values 时序（与检索模式 filings 列表不同——营收份额经 values 序列计算并标注口径）
- **china-nbs**：宏观/行业总量口径，不提供企业级份额数据——份额结论须「行业→企业」显式映射推断并标注，或降级为行业格局定性判断
- **newsapi**：以英文新闻覆盖为主（中文 query 可用但覆盖有限——4-1f 起 CJK query 自动注入 language=zh）
- **tavily**：Web 事件级检索（非结构化指标级；4-1f 起 CJK query 自动注入 country=china）

## 禁止事项

- 禁止用同一来源的不同指标互相"印证"（伪三角化）
- **同一来源的多个 query（name/name#2 键）不构成独立来源**，不得计入印证数
- 禁止在 sources 字段中登记未实际采集的来源
- 缓存命中（cache_hit=true）的数据仍计入印证，但必须结合 freshness_score 评估时效性
- 专利结论仅以单库（uspto/google-patents/epo-ops 任一）成立时，标注「单库口径」并下调置信度；两库及以上互证方可视为专利域内印证成立（域内一致性，非跨域互证——对齐 disruptive 侧纪律）
