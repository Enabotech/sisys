# RACI 角色任务采集模板

> 工作坊现场填写；采集字段与 SKILL.md `input_schema` 一一对应（roles_tasks 为
> 嵌套分区，分区内字段即 Schema 叶子键）。规则判定标准见 `references/validation_rules.md`。

## 基本信息

| 字段 | 说明 |
| --- | --- |
| 分析对象 | 项目/流程名称 |
| 组织范围 | 涉及部门与团队 |
| 工作坊日期 | 填写日期 |
| 引导者/记录员 | 名字 |

## 采集表格

### roles_tasks

| 字段 | 值（编码示例） | 证据来源 |
| --- | --- | --- |
| roles（必填） | 产品经理、架构师、开发负责人、测试负责人 | 岗位说明书 |
| tasks（必填） | 需求分析、方案设计、编码实现、系统测试 | 流程文档 |
| assignments（必填） | 需求分析→产品经理＝A/R、架构师＝C；方案设计→架构师＝A/R | 矩阵速查表定稿 |

> roles/tasks 以顿号分隔逐项登记；assignments 按双层编码「任务名→角色名＝RACI 字母组合」逐任务一行（一行可含多组，组间以分号分隔、组内以顿号分隔——任务名/角色名请避免「、」「；」「→」「＝」防行内速记解析歧义，转写为 arguments 后无此限制），与矩阵速查表一一对应。

## 校验规则

恰 1 A 硬规则 + ≥1 R 软规则（A/R 计为已承担 R）等逐条编号规则见 `references/validation_rules.md`；
任务→角色映射的系统化思考步骤见 `references/framework_logic.md`。

## 数据缺口登记

| 字段 | 缺口描述 | 替代来源 |
| --- | --- | --- |
| assignments | 部分任务的咨询对象（C）待确认 | 会后与缺席角色代表确认 |
| tasks | 跨部门流程的下游任务清单不完整 | 流程责任人补充 |

## RACI 矩阵速查

> 工作坊现场承载形态：任务为行、角色为列的矩阵表格，单元格填 RACI 字母组合
> （单字母或斜线组合如 A/R）。行首列任务名 = assignments 外层键，表头列角色名 =
> 内层键——与双层编码结构一一对应，定稿后逐格转录。

| 任务\角色 | 产品经理 | 架构师 | 开发负责人 | 测试负责人 |
| --- | --- | --- | --- | --- |
| 需求分析 | A/R | C | | I |
| 方案设计 | C | A/R | C | |
| 编码实现 | | C | A/R | I |
| 系统测试 | I | | R | A/R |
