# 情景数据三角化规范

> 目的：情景规划的驱动因素必须有实证数据支撑（源级分工采集——3 个声明源各司其职），
> 避免凭想象构建情景轴。

## 3 源角色分工

| 来源 | 角色 | 典型印证驱动因素 |
|------|------|----------------|
| ipcc | 权威情景数据主源 | 气候情景（SSP 路径）、碳排放、温控目标 |
| eurostat | 区域官方统计 | 能源结构、产业转型、人口与消费趋势（欧盟） |
| tavily | 趋势情报印证 | 新兴技术扩散、政策风向、社会舆情 |

## 三角化流程

1. **驱动因素声明**：Think 阶段声明 5-8 个候选驱动因素
2. **来源映射**：每个驱动因素映射其专职源（ipcc→气候与环境类、eurostat→能源与经济
   结构类、tavily→技术与社会趋势类——源级分工而非维度级多源映射）；跨类一致性经
   情景逻辑交叉检验（同一驱动因素在多情景间的一致性）
3. **独立采集**：各来源独立采集（`$DATA_SOURCE` 标记并发执行）；类内多信号经同源多
   query 采集——同源多 query 不构成独立来源
4. **交叉比对**：
   - 官方数据（ipcc/eurostat）与趋势情报（tavily）方向一致 → 印证成立
   - 方向矛盾 → 以官方数据为准构建基准情景，趋势情报用于标识新兴不确定性
5. **来源登记**：每个驱动因素在情景剧本 `driving_forces` 中如实标注数据来源；
   专职源缺失时标注「单源支撑」并下调置信度

## 冲突裁决

- 优先级：官方统计（ipcc / eurostat）> 趋势情报（tavily）
- 时效优先：同优先级取 `source_timestamp` 更新者
- 裁决理由必须记录在情景叙事中

## 数据源口径边界

- ipcc：全球气候科学口径
- eurostat：欧盟口径（region_scope 非 eu 时能源经济数据仅作全球参照，不作主证）
- tavily：Web 事件级检索（非结构化指标级）

## 禁止事项

- 禁止构建无任何数据支撑的驱动因素（"拍脑袋情景"）
- 禁止用同一来源的多个 query（name/#2 键）互相"印证"（伪三角化——独立性以源为单位，同源多 query 不构成独立来源）
- 禁止在 driving_forces 中登记未实际采集的来源
- 缓存命中的数据仍计入印证，但须结合 freshness_score 评估时效性
