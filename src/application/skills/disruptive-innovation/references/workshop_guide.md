# 颠覆性创新评估工作坊 + 专家访谈提纲

> 适用：战略/技术团队 0.5-1 天颠覆风险评估工作坊。本工具输出（颠覆信号清单 +
> 技术成熟度初判）作为工作坊的数据输入。

## 工作坊流程

| 阶段 | 时长 | 活动 | 产出 |
|------|------|------|------|
| 1. 议题对齐 | 15' | 确认技术领域与在位行业 | 议题声明 |
| 2. 数据回顾 | 30' | 展示四源采集结果与信号初评（含跨域互证状态） | 数据共识 |
| 3. 信号质询 | 60' | 逐信号挑战：互证成立吗？是专利泡沫还是舆情泡沫？ | 信号共识清单 |
| 4. 成熟度合议 | 30' | 对照锚点判定技术成熟度 | 成熟度结论 |
| 5. 颠覆路径研判 | 45' | 低端/新市场/无颠覆三路径研判 | 颠覆路径结论 |
| 6. 应对策略 | 60' | 在位者防御 / 颠覆者进攻策略研讨 | 策略行动项 |

## 角色分工

- **引导师**：控场，确保评估基于专利三库 + 市场跨域证据
- **技术专家**：解读专利信号（专利质量 vs 数量）
- **市场专家**：解读市场信号（真实采纳 vs 媒体炒作）
- **挑战者**：专职识别"专利泡沫/舆情泡沫/隐性颠覆"三种误判模式

## 专家访谈提纲（工作坊外部输入，可选）

> **使用边界（反虚构纪律）**：访谈提纲供真人专家使用（工作坊外部输入）；LLM 不得代答、
> 模拟专家观点或将未采集的访谈内容写入输出——所有输出观点须溯源至注入数据。

### 技术侧专家（访谈 45'）
1. 该技术领域近 3 年最关键的专利突破是什么？谁在布局？
2. 性能提升斜率是否在加速？距离主流市场性能要求还有多远？
3. 哪些技术瓶颈一旦突破会改变竞争格局？

### 市场侧专家（访谈 45'）
1. 边缘市场/低端客群的采纳真实驱动是什么（价格？便利？新场景）？
2. 在位者的应对是否有效？为什么（不）？
3. 未来 2 年最可能出现的价格性能比拐点是什么？

## 引导话术

- 评级争议时：「这个信号的市场侧印证是什么？没有互证就封顶 0.5」
- 悲观/乐观偏差时：「我们分别看看专利源和市场源各自显示什么——偏差来自哪一侧？」

## 会后跟进

- 观察信号（0.3-0.5）纳入季度监测（复跑本工具比对信号强度变化）
- 颠覆窗口期信号（≥0.7）触发专项战略复审
