# 双源交叉验证规范（专利 ↔ 市场情报）

> 目的：本工具仅声明 2 个数据源（uspto / tavily，决策 D4），颠覆信号必须通过
> 专利数据与市场情报的双源互证，避免单一来源造成颠覆误判（专利泡沫或舆情泡沫）。

## 双源角色分工

| 来源 | 角色 | 典型信号 |
|------|------|---------|
| uspto | 技术供给侧实证 | 专利申请趋势、核心专利布局、新进入者专利占比 |
| tavily | 市场需求侧情报 | 融资事件、商业化进展、客户采纳、价格性能拐点报道 |

## 交叉验证流程

1. **信号假设**：Think 阶段声明候选颠覆信号（专利/市场/技术三类）
2. **双源采集**：uspto 与 tavily 独立采集（`$DATA_SOURCE` 标记并发执行）
3. **互证判定**：
   - **强互证**：专利活跃度上升 + 市场商业化进展同步出现 → 信号强度可评 >0.7
   - **弱互证**：一侧活跃另一侧仅有间接信号 → 强度 0.5-0.7
   - **无互证**：仅单源信号（如专利活跃但无商业化进展="专利泡沫"特征）→ 强度封顶 0.5
   - **互斥**：双源信号方向矛盾（如专利活跃但市场持续唱衰）→ 记录矛盾，强度 ≤0.4 并标注
4. **来源登记**：每个信号 `sources` 字段如实登记互证来源（单源信号显式标注"单源"）

## 典型误判模式（必须识别并标注）

| 模式 | 特征 | 判定 |
|------|------|------|
| 专利泡沫 | uspto 专利激增但 tavily 无商业化信号 | 萌芽期技术，颠覆威胁低近期 |
| 舆情泡沫 | tavily 热炒但 uspto 无实质专利布局 | 概念炒作，禁止高评级 |
| 隐性颠覆 | 专利平稳但边缘市场采纳加速（tavily） | Christensen 新市场颠覆典型，重点关注 |

## 禁止事项

- 禁止单源信号评级 >0.5（双源互证是高评级前提）
- 禁止在 sources 字段登记未实际采集的来源
- 缓存命中的数据仍计入互证，但须结合 freshness_score 评估时效性
