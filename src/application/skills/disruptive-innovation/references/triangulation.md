# 跨域交叉验证规范（专利双库 ↔ 市场情报）

> 目的：本工具声明 3 个数据源（uspto / epo-ops / tavily——4-1f D8 重开后升级，决策 D4），
> 颠覆信号必须通过专利域（US+EP 双库）与市场域（tavily）的跨域互证，避免单一来源
> 造成颠覆误判（专利泡沫或舆情泡沫）。

## 三源角色分工

| 来源 | 角色 | 典型信号 |
|------|------|---------|
| uspto | 技术供给侧实证（US 口径） | 专利申请趋势、核心专利布局、新进入者专利占比（标题软归因） |
| epo-ops | 技术供给侧实证（EP 口径） | 专利申请趋势、申请人结构化归因（`pa=` 支持中文企业名——与 uspto 双库印证专利域内部一致性） |
| tavily | 市场需求侧情报 | 融资事件、商业化进展、客户采纳、价格性能拐点报道 |

## 交叉验证流程

1. **信号假设**：Think 阶段声明候选颠覆信号（专利/市场/技术三类）
2. **三源采集**：uspto / epo-ops / tavily 独立采集（`$DATA_SOURCE` 标记并发执行）
3. **互证判定**（两级：专利域内双库一致 + 专利×市场跨域互证）：
   - **强互证**：专利域双库一致活跃 + 市场商业化进展同步出现 → 信号强度可评 >0.7
   - **弱互证**：一侧活跃另一侧仅有间接信号 → 强度 0.5-0.7
   - **无互证**：仅单域信号（如专利域（单库或双库）活跃但无商业化进展="专利泡沫"特征）→ 强度封顶 0.5
   - **互斥**：专利域与市场域信号方向矛盾（如专利活跃但市场持续唱衰）→ 记录矛盾，强度 ≤0.4 并标注
   - **双库分歧**：uspto 与 epo-ops 专利趋势矛盾 → 标注「US/EP 口径分歧」，以 `source_timestamp` 更新者优先并记录
4. **来源登记**：每个信号 `sources` 字段如实登记互证来源（单域信号显式标注"单域/单库"）

## 典型误判模式（必须识别并标注）

| 模式 | 特征 | 判定 |
|------|------|------|
| 专利泡沫 | 专利域（uspto/epo-ops）活跃但 tavily 无商业化信号 | 萌芽期技术，颠覆威胁低近期 |
| 舆情泡沫 | tavily 热炒但专利域无实质布局 | 概念炒作，禁止高评级 |
| 隐性颠覆 | 专利平稳但边缘市场采纳加速（tavily） | Christensen 新市场颠覆典型，重点关注 |

## 数据源口径边界

- **uspto**：仅美国专利口径；标题关键词匹配（归因经 assignees 字段研判）
- **epo-ops**：EPO 欧洲专利口径（`pa=` 申请人结构化检索支持中文企业名，100+ 专利局含 CN——仅 EP 申请视角；与 uspto 合并后仍缺 CNIPA 中国本土口径，按「US+EP 双口径」标注）；周配额 4GB/周，耗尽时回落 uspto 单库并标注
- **tavily**：Web 事件级检索（非结构化指标级；CJK query 自动注入 country=china）

## 禁止事项

- 禁止单域信号评级 >0.5（跨域互证是高评级前提——专利域双库互证仅证明专利域内部一致性，不构成跨域互证）
- 同一来源的多个 query（name/name#2 键）不构成独立来源，不得计入互证数
- 禁止在 sources 字段登记未实际采集的来源
- 缓存命中的数据仍计入互证，但须结合 freshness_score 评估时效性
