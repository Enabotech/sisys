# 技术成熟度锚点 + 颠覆信号强度分级

## 技术成熟度四级判定（基于双源证据）

| 级别 | 判定特征（专利源 uspto） | 判定特征（市场源 tavily） |
|------|------------------------|--------------------------|
| 萌芽期 | 专利申请起步，以高校/研究院所为主 | 几乎无商业化报道，以科研成果为主 |
| 成长期 | 专利申请年增 >20%，企业申请人占比上升 | 融资事件频现，首批商业化试点 |
| 成熟期 | 专利申请趋稳，头部企业专利布局完成 | 规模化商业应用，供应链成熟 |
| 衰退期 | 专利申请下降，被新技术路线替代 | 市场份额萎缩，投资撤离 |

## 颠覆信号强度分级（0-1）

| 分值区间 | 含义 | 双源互证要求 |
|---------|------|-------------|
| 0.85-1.00 | 颠覆进行中 | 强互证：专利+市场同步爆发，在位者已受冲击 |
| 0.70-0.85 | 颠覆窗口期 | 强互证：技术性能逼近拐点 + 边缘市场采纳加速 |
| 0.50-0.70 | 潜在颠覆信号 | 弱互证：一侧强信号 + 另一侧间接印证 |
| 0.30-0.50 | 观察信号 | 单源信号（封顶 0.5），需持续监测 |
| 0.00-0.30 | 无颠覆信号 | 双源均平稳或互斥 |

## Christensen 颠覆路径判定

### 低端颠覆（Low-end Disruption）
- 信号组合：新进入者以"够用就好"的低价产品服务被过度服务的客群
- 数据特征：价格性能比拐点报道（tavily）+ 低成本技术专利布局（uspto）

### 新市场颠覆（New-market Disruption）
- 信号组合：技术将非消费者转化为消费者，开辟全新应用场景
- 数据特征：边缘场景采纳报道（tavily）+ 应用导向专利增长（uspto）

### 无颠覆信号
- 双源均显示维持性演进特征 → `innovation_assessment` 明确说明无颠覆风险及依据
