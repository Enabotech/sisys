# BSC 平衡计分卡内外数据融合规范

> 本 Skill 的交叉验证主轴是「外部基准 ↔ 内部数据」：内部数据（战略规划要点 + KPI 现值，
> 高管工作坊采集）是设计主体，外部源（国家统计局/World Bank）仅支撑财务维度的对标基准。

## 融合流程

1. **内部数据定基**：高管工作坊采集的四维度目标与 KPI 现值（模板 `templates/bsc_kpi_scorecard.md`）
   是计分卡骨架——外部数据不新增内部 KPI 条目
2. **外部对标（仅财务维度）**：——
   - 国家统计局（行业统计）：行业营收/成本/薪酬水平校准财务目标值的量级
   - World Bank（宏观指标）：GDP 增速（NY.GDP.MKTP.KD.ZG）/实际利率（FR.INR.RINR）
     校准增长与折现假设
3. **档位校准**：KPI 目标值显著偏离行业基准（±50% 以上）时按锚点档位修正并标注内部依据

## 冲突处理（外部基准与内部目标矛盾）

| 矛盾类型 | 处置 |
| --- | --- |
| 内部目标增速远超行业/宏观基准 | 双方并列呈现：保留内部目标 + 标注「超额假设」，要求给出市场份额内部依据 |
| 行业统计口径与内部口径不一致 | 以内部口径为准，外部基准换算后参照，登记口径差异于缺口区 |
| 统计数据滞后（NBS 年度数据发布延迟） | 沿用最近可得期并标注数据时点，超 18 个月列入缺口区 |

## 内外结论权重

- **四维度 KPI 体系结构（指标/权重/因果链）**：内部数据权重 100%（外部源不设计内部 KPI）
- **财务维度目标值**：内部预期为分析主体，行业/宏观基准用于校准印证（非数值加权——BSC
  不做加权总分）；矛盾处置按冲突表分级裁决，校准结果双方并列呈现
- **客户/内部流程/学习成长维度目标值**：以历史值/目标值为基准——外部源无这三维度对标能力，
  **禁止伪造外部对标**（如需跨企业参照，登记缺口区由内部调研补充）

## 基准粒度限制声明

World Bank 宏观指标是**国家维度**，国家统计局行业统计是**门类/大类行业维度**：
- 适用于：财务维度目标值的宏观环境与行业量级校准（仅财务维度有真实外部基准）
- 不适用于：客户/内部流程/学习成长维度——这三维度以企业历史值/目标值为基准
- 时效边界：NBS 爬虫 TTL 1 天 / WB 指标 TTL 7 天，跨年度目标值需重新对标
