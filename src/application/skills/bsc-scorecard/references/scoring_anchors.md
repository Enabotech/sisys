# BSC KPI 目标档位评分锚点（保守/基准/挑战三档）

> 刻度声明：本 Skill 对每条 KPI 目标值按**三档目标刻度**（保守/基准/挑战）定位，
> 定档主体为高管工作坊（引导者防锚定，见 workshop_guide.md）；
> 财务维度档位须对照行业/宏观基准校准（规则见 data_fusion.md）。

## 分档含义

R2-F6 区间连续化（原三段概率带 80-90%/50-60%/<30% 无归属，边界目标无法定档）：

| 档位 | 判定标准 |
| --- | --- |
| 保守 | 达成概率 ≥90%，等于或略高于历史值延续（不构成战略牵引） |
| 基准 | 达成概率 60%（含）-90%，对照行业均值/宏观基准外推（战略牵引与可达性平衡） |
| 挑战 | 达成概率 30%（含）-60%，显著超出行业/历史外推（需结构性举措支撑） |
| 不可信目标区 | 达成概率 <30%：**禁止直接定档**——须补结构性举措重新论证，或退回挑战档并登记复议 |

## 与 kpi-tree 档位互查映射（R2-F6：两 Skill 互相负向跳转，同名档位判据不同）

两套档位是「常规可达目标」的两种定档依据，**非 1:1 对称**：

| BSC 档位（达成概率口径） | kpi-tree 档位（行业分位口径） | 映射说明 |
| --- | --- | --- |
| 保守 | —（无对应档） | kpi-tree 最低档为基准（行业中位），低于中位的目标不进入 KPI 树分解 |
| 基准 | 基准（行业中位） | 同一「常规可达」语义：无官方统计时用概率法，有统计时用分位法 |
| 挑战 | 挑战（行业前 1/4）或 突破（逐一论证） | 挑战档细分：有行业分位数据对应挑战，超出行业天花板对应突破 |
| —（无对应档） | 突破（超行业天花板） | 超出 BSC 挑战上限，BSC→kpi-tree 传递时须复议登记 |

> 两 Skill 同用（BSC 定目标 → kpi-tree 分解）时档位冲突取保守侧，并在 KPI 树
> 分解表中登记档位换算依据。

## 锚点示例（财务维度，含外部对标）

- **基准正例**：营收增速目标 = 行业均值 + 2pct（NBS 行业统计外推 + 份额提升假设）
- **挑战正例**：毛利率目标 38%（历史 31% + 产品结构升级举措清单支撑）
- **挑战反例**：营收翻倍且无举措清单支撑（目标档位与行动资源脱节——挑战档必须有行动计划闭环）

## 锚点示例（客户/流程/学习维度，内部基准）

- **基准正例**：大客户续约率 85%（历史 78% + 交付提效因果链假设支撑）
- **保守反例**：人均培训 40 学时等于去年现值延续（保守档仅用于过渡期指标，不作为战略 KPI 主档）

## 聚合规则

- 逐 KPI 定档，维度内不做加权总分（BSC 是因果链体系而非单一评分卡）
- 权重分配：四维度权重和 = 100%，单维度不低于 15%（失衡即回归工作坊复议）
- 因果链闭合：学习成长 → 内部流程 → 客户 → 财务的假设方向必须可追溯；
  外部基准仅参与财务维度档位校准，其余三维度以历史值/目标值为基准
