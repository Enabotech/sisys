# BSC 四维度 KPI 计分卡

> 高管工作坊现场填写；采集字段与 SKILL.md `input_schema` 一一对应（战略目标为嵌套分区，
> 分区内字段即 Schema 叶子键）。目标档位标准见 `references/scoring_anchors.md`。

## 基本信息

| 字段 | 说明 |
| --- | --- |
| 分析对象 | 目标企业/业务单元名称 |
| 计分卡周期 | 如 2027 年度（战略期间 2026-2030） |
| 工作坊日期 | 填写日期 |
| 引导者/记录员 | 名字 |
