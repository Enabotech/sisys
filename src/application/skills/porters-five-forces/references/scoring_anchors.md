# 五力强度评分锚点（0-1）

> 波特五力 Skill 评分一致性规范。score ∈ [0, 1]，**越大压力越强**
> （对行业在位者/进入者而言该力带来的竞争压力越大，行业吸引力越低）。

## 1. 通用分档

| 分档 | 区间 | 语义 |
|------|------|------|
| 弱 | 0.0 - 0.25 | 该力几乎不构成压力，证据零星 |
| 中偏弱 | 0.25 - 0.45 | 有压力迹象但结构性证据不足 |
| 中偏强 | 0.45 - 0.65 | 压力明确，多源证据方向一致 |
| 强 | 0.65 - 0.85 | 压力显著，三源印证且趋势延续 |
| 极强 | 0.85 - 1.0 | 压力主导行业利润分配，证据充分且事件频发 |

## 2. 各力锚点示例

### 现有竞争

- **0.2（弱）**：行业 CR5 < 30%，差异化明显，无价格战舆情（如高端定制设备）
- **0.5（中偏强）**：CR5 40-60%，偶有促销战，产能利用率 75-85%（如白电行业）
- **0.8（强）**：CR5 > 70% 且同质化，价格战/并购新闻频发，产能利用率 < 70%（如动力电池）

### 新进入者威胁

- **0.2（弱）**：资本/牌照/技术壁垒高，近三年无规模化新进入者新闻（如民用航空制造）
- **0.5（中偏强）**：存在跨界进入传闻与融资事件，但尚未量产（如固态电池新玩家）
- **0.8（强）**：新进入者融资/建厂新闻频发，营商便利度高、进入周期短（如茶饮连锁）

### 替代品威胁

- **0.2（弱）**：无成熟替代技术路线，替代渗透率 < 5%（如航空煤油对长途航运）
- **0.5（中偏强）**：替代技术进入商用初期，渗透率 5-15% 且成本曲线下降（如磷酸铁锂对三元）
- **0.8（强）**：替代品性价比已交叉，渗透率 > 20% 且加速（如电动车对燃油车）

### 供应商议价力

- **0.2（弱）**：上游充分竞争，原材料占成本 < 20%，无涨价舆情（如软件服务业）
- **0.5（中偏强）**：上游局部集中，大宗价格波动传导滞后（如家电用钢材）
- **0.8（强）**：上游寡头垄断 + 纵向整合威胁，涨价/断供新闻频发（如锂矿对动力电池）

### 购买者议价力

- **0.2（弱）**：下游极度分散，转换成本高，无集采招标（如消费级 SaaS 长尾客户）
- **0.5（中偏强）**：下游有区域性集采，大客户占比 20-40%（如建材对房企）
- **0.8（强）**：下游寡头采购，招标压价常态化，大客户占比 > 50%（如动力电池对头部车企）

## 3. 评分纪律

- 评分必须引用 `evidence` 中的具体观测值/事件，禁止凭印象打分
- 3 源直接映射或 2 源直接映射 + 跨力关联印证充分的力方可进入「强 / 极强」档；仅 2 源直接印证且无关联印证上限为「中偏强」；单源印证上限为「中」
- 事件驱动型上调（突发并购/断供）须在 evidence 标注「事件驱动」并在下期复核
