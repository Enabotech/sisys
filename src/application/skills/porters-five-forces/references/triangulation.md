# 五力三角化规范

> 波特五力 Skill 多源印证操作规范。本 Skill 声明源共 3 个
> （newsapi / world-bank / eurostat），三角化为**源级三角化**：3 个声明源全部参与
> 采集；力级直接映射源数以 SKILL.md §5 映射表为准（仅「现有竞争」为 3 源直接映射，
> 其余四力为 2 源）——直接映射不足的力经跨力关联印证补足，否则按缺口登记下调证据强度。

## 1. 三源分工

| 数据源 | 角色 | 主要印证内容 | 时效特征 |
|--------|------|-------------|---------|
| newsapi | 舆情与事件源 | 竞争动态、并购、价格战、新进入者、供应链事件、大客户招标 | 实时（TTL 6 小时） |
| world-bank | 宏观与结构源 | 行业增加值、固定资产投资、营商便利度、大宗贸易指标 | 年度（TTL 7 天） |
| eurostat | 区域行业结构源 | 欧盟行业企业数、营业额结构、上下游采购结构 | 年度（TTL 7 天） |

## 2. 印证流程

1. **指标落位**：Think 阶段将每个力的关键指标映射到源（见 SKILL.md §5 映射表——
   力级直接映射以表为准，不足 3 源的力声明跨力关联印证路径）
2. **独立采集**：3 源并发采集全部参与，互不影响；单源失败走失败处理降级（SKILL.md §7）
3. **交叉比对**：同一指标在多源中的观测值/信号方向逐一比对
4. **强度定级**：印证源方向一致且达 3 源（直接或含关联印证）→ 证据强度「强」；
   2 源一致 + 1 源缺失或无关联印证 → 「中」；方向冲突 → 进入冲突裁决（§3）

## 3. 冲突裁决

当多源信号方向冲突时，按以下优先级裁决：

1. **时效优先**：同一指标以 source_timestamp 最新者为主证，旧数据标注时效衰减
   （freshness_score 已折算）
2. **粒度优先**：行业级结构指标（world-bank / eurostat）优先于新闻舆情的个案信号；
   但突发事件（并购、政策突变）以 newsapi 为先导信号并在 evidence 中标注「事件驱动」
3. **区域匹配优先**：region_scope=eu 时 eurostat 权重上调；region_scope=china 时
   eurostat 仅作全球参照，不作主证
4. **禁止调和编造**：冲突无法裁决时，如实登记双方证据并在 evidence 中说明分歧，
   禁止取平均数制造虚假一致

## 4. 缺口登记

任一力缺失来源印证时：
- `sources` 字段只登记实际印证来源
- `evidence` 中显式标注「数据缺口：缺失 X 源印证」
- 该力 score 置信度下调一档（强→中，中→弱），并在 `data_sources` 溯源元数据中反映

## 5. 禁止事项

- 禁止用同一来源的不同指标或多个 query（name/#2 键）互相"印证"（伪三角化——独立性
  以源为单位，同源多 query 不构成独立来源，不得计入印证数）
- 禁止在 sources 字段中登记未实际采集的来源
- 禁止以 LLM 先验知识替代采集证据充当「来源」
