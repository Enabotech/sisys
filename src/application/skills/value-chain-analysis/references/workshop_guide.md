# 价值链流程访谈 + ERP 导出引导（2-4 小时结构化）

> 形态说明：本 Skill 的采集形态是**流程访谈 + ERP 导出**（非开放式头脑风暴）——
> 逐活动负责人半日结构化访谈 + 财务口径对齐会收口。

## 会前准备（T-3 天）

| 时点 | 动作 | 产出 |
| --- | --- | --- |
| T-3 天 | 分发 `templates/value_chain_activities_inventory.md` 与预填指引给各活动负责人 | 各自预填活动草稿（不汇总，防锚定） |
| T-2 天 | 财务导出 ERP 活动科目成本表（近 4 季），并与活动清单对齐科目映射 | 成本归属初稿 + 口径映射表 |
| T-1 天 | 引导者汇总外部基准速览（Tavily 行业结构情报 + 国家统计局行业统计标题级） | 速览页（仅事实，不预判贡献） |

## 现场流程（2-4 小时）

| 环节 | 时长 | 产出物 |
| --- | --- | --- |
| 开场与规则宣讲 | 15 min | 活动边界与纪律共识（防锚定/防护短） |
| 主要活动逐条盘点 | 40 min | primary_activities 清单 + 贡献评分 |
| 支持活动逐条盘点 | 30 min | support_activities 清单 + 贡献评分 |
| 成本归属对齐 | 30 min | cost_structure 定稿（活动 → 金额/占比） |
| 外部基准对照校准 | 30 min | 校准后贡献评分（矛盾项登记复议） |
| 优势/降本环节预演 | 20 min | 优势环节与降本候选清单（Agent 深化输入） |

## 时间压缩指引（2 小时精简变体）

| 环节（精简版） | 时长 | 说明 |
| --- | --- | --- |
| 开场与规则宣讲 | 15 min | 纪律宣讲不可压缩 |
| 主要活动逐条盘点 | 30 min | 活动上限 8 条 |
| 支持活动逐条盘点 | 20 min | 活动上限 4 条 |
| 成本归属对齐 | 20 min | 仅对齐主要活动 |
| 外部基准对照校准 | 20 min | 仅校准高成本环节 |
| 优势/降本环节预演 | 15 min | — |

- **压缩代价**：活动清单粒度下降，被裁活动转入数据缺口登记区会后补采
- **不可压缩项**：防锚定/防从众纪律宣讲、证据来源登记、数据缺口登记——省略即失效

## 角色分工

- **引导者**：控流程/控时/执行纪律，不参与内容判断
- **活动负责人**（逐环节参与）：本环节活动清单与贡献评分的提出与答辩主体
- **财务代表**：ERP 成本口径解释与活动科目映射裁定
- **记录员**：实时填写盘点清单，逐条登记证据来源与数据缺口

## 引导纪律

- **防锚定**：预填草稿访谈开场后才公开；禁止以「上年活动清单」为起点修修补补
- **防护短**：负责人为本人环节打分须举证客户价值链条；「都重要」即无效评分，当场追问差异化
- **防混同**：成本金额大 ≠ 价值贡献高（成本与贡献两轴分开评，混同即作废重评）
- 单环节讨论超 10 分钟即登记「待议」移入缺口登记区，口径对齐会裁定

## 会后跟进

1. 记录员 24h 内回收定稿清单，补齐缺口登记区的替代来源
2. 按模板「采集表格」字段构造 `input_schema` 参数：
   `enterprise_data.{primary_activities, support_activities, cost_structure}`
   （每条活动携带贡献评分与证据来源，供 Agent 融合外部基准时校准）
3. 调用本 Skill 执行：Agent 结合外部基准（Tavily/国家统计局对照）生成价值贡献与优势定位
4. 结果回传业务负责人确认（重点：外部对照与内部判断的矛盾项处置与降本清单采纳）
