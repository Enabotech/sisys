# 价值链分析内外数据融合规范

> 本 Skill 的交叉验证主轴是「外部基准 ↔ 内部数据」：企业内部活动清单与成本归属
> （ERP 导出 + 流程访谈）是分析主体，外部源（Tavily/国家统计局）仅提供行业对照参照。

## 融合流程

1. **内部数据定基**：活动盘点清单（模板 `templates/value_chain_activities_inventory.md`）
   是价值链的骨架——主要/支持活动清单与成本归属以内部数据为准，
   外部源不新增/不改写内部活动划分（活动边界以流程访谈共识为准）
2. **外部对照**：逐环节对照外部基准——
   - Tavily（行业结构情报）：行业价值链分工形态/外包惯例/标杆环节实践是否支持
     该环节的价值贡献判断
   - 国家统计局（官方行业统计）：分行业收入/成本官方统计为成本占比与盈利水平
     提供中国行业维度对标
3. **贡献校准**：外部对照充分（≥1 源直接印证）时活动价值贡献评分可上调；
   仅有内部判断时评分下调一档并标注「未经外部对照」

## 冲突处理（外部基准与内部判断矛盾）

| 矛盾类型 | 处置 |
| --- | --- |
| 外部有证据、内部未识别（行业普遍外包的高成本环节） | 外部基准优先：登记为候选改进项，标注「外部信号，待内部复议」 |
| 内部判断为优势环节、外部无印证 | 双方并列呈现：保留内部判断 + 标注「未经外部对照」，不下结论 |
| 外部统计与内部成本口径相反 | 暂停判断：列入访谈复议清单，核对口径（含税/口径范围）后修正 |

## 内外结论权重

- **活动清单与成本归属**：内部数据权重 100%（外部源不评判内部活动划分）
- **价值贡献与优势定位**：内部判断为分析主体，外部基准用于校准印证（非数值加权——价值链
  分析不做加权总分）；矛盾处置按冲突表分级裁决，校准结果并列呈现于优势环节依据
- **降本机会排序**：以校准后的贡献评分与成本占比为输入，排序逻辑不受数据来源影响

## 基准粒度限制声明

china-nbs 是**中国官方行业统计**：其口径是行业维度（如分行业营业收入/成本），
不提供「某价值链环节」的直接成本数据（环节对标须经「行业 → 环节」的显式映射并标注假设）。
Tavily 为 Web 检索源，其覆盖是**行业事件级**而非**结构化指标级**：适用于分工形态与标杆
实践的定性印证，不适用于成本占比定量基准。时效边界：两源 TTL 均 24h，
超过 TTL 的结论需重新采集对照。
