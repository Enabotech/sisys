# 价值链活动价值贡献评分锚点（1-5 刻度）

> 刻度声明：本 Skill 采用 **1-5 整数刻度**（1 = 无贡献，5 = 决定性贡献），对主要/支持
> 活动逐环节评分（区分「价值创造」与「成本发生」：高成本未必高贡献）。
> 评分主体为流程访谈业务专家（引导者防锚定，见 workshop_guide.md）。

## 分档含义

| 分值 | 贡献档位 | 判定标准 |
| --- | --- | --- |
| 5 | 决定性 | 该环节直接构成客户付费理由与差异化来源，行业标杆也难以复制 |
| 4 | 显著 | 对客户价值与毛利有重大贡献，具备相对行业基准的优势 |
| 3 | 中等 | 必要环节但同质化，贡献与行业中位持平 |
| 2 | 边际 | 间接支持价值创造，改进空间与外包候选性较高 |
| 1 | 无贡献 | 仅发生成本不创造可识别价值（冗余/待整合环节） |

## 锚点示例

- **5 分正例**：电芯配方研发——能量密度行业领先，客户定点核心依据（技术开发活动）
- **3 分正例**：整机厂直供物流——必要但竞对同水准（发货活动）
- **1 分反例**：纸质档案库房管理——纯成本发生，无客户价值关联（基础设施活动）

## 成本视角补充判据（配合 cost_structure）

- 高贡献 + 高成本 → 投资强化（保护优势环节的投入优先级最高）
- 高贡献 + 低成本 → 优势环节（对外宣传与复制推广）
- 低贡献 + 高成本 → 降本/外包首选（对照 Tavily 行业外包惯例印证）
- 低贡献 + 低成本 → 维持现状登记备查

## 聚合规则

- 活动不做加权总分（价值链是结构地图而非评分卡）
- 竞争优势环节入选：贡献评分 ≥4 且经外部基准对照印证
- 贡献评分 <2 的活动全部进入降本/外包候选清单（按成本占比降序排列）
- 校准后评分变化超过 1 档的，须在定位依据中登记对照来源
