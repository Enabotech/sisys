# SWOT-TOWS 内外数据融合规范

> 本 Skill 的交叉验证主轴是「外部基准 ↔ 内部数据」：内部因素（工作坊采集）是分析主体，
> 外部源（NewsAPI/Tavily）仅提供机会/威胁的印证参照。

## 融合流程

1. **内部数据定基**：工作坊采集的四象限因素清单（模板 `templates/swot_factors_collection.md`）
   是 SWOT 的骨架——外部数据不新增内部优势/劣势条目（内部能力判断以工作坊共识为准）
2. **外部印证**：每条机会/威胁对照外部基准印证——
   - NewsAPI（行业时政）：政策变动/市场事件/监管动态是否支持该机会/威胁的成立性
   - Tavily（竞争情报）：竞品动向/新进入者/替代技术是否与威胁判断一致
3. **强度校准**：外部证据充分（≥1 源直接印证）时因素强度可上调；仅有内部认知时强度下调一档并标注

## 冲突处理（外部基准与内部认知矛盾）

| 矛盾类型 | 处置 |
| --- | --- |
| 外部有证据、内部未识别（漏判的机会/威胁） | 外部基准优先：补充为候选条目，标注「外部信号，待内部评估」 |
| 内部判断为威胁、外部无印证 | 双方并列呈现：保留内部判断 + 标注「未经外部印证」，不下结论 |
| 外部情报与内部判断方向相反 | 暂停判断：列入工作坊复议清单，以最新一手内部数据为准修正 |

## 内外结论权重

- **优势/劣势（内部象限）**：内部数据权重 100%（外部源不评判内部能力）
- **机会/威胁（外部象限）**：内部认知为分析主体，外部基准用于校准印证（非数值加权——
  SWOT 不做加权总分）；矛盾处置按冲突表分级裁决，校准结果并列呈现于 TOWS 推导依据
- **TOWS 匹配**：以校准后的四象限强度为输入，匹配逻辑不受数据来源影响

## 基准粒度限制声明

NewsAPI/Tavily 为新闻与 Web 检索源，其覆盖是**行业事件级**而非**结构化指标级**：
- 适用于：事件性机会/威胁印证（政策发布/融资事件/竞品动作）
- 不适用于：市场规模/增速等定量基准（如需定量，结合 ansoff-matrix 的 World Bank/IMF 链路）
- 时效边界：新闻源 TTL 6h/24h，超过 TTL 的结论需重新采集印证
