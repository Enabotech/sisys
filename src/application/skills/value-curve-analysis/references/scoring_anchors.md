# 价值要素水平评分锚点（1-5 刻度）

> 刻度声明：本 Skill 采用 **1-5 整数刻度**（1 = 极低投入/极弱水平，5 = 极高投入/极强水平），
> 对价值曲线各主体（行业/竞品/我方当前/我方目标）逐要素评分。评分主体为调研分析员与业务专家
> （引导者防锚定，见 workshop_guide.md）。

## 分档含义

| 分值 | 强度 | 判定标准 |
| --- | --- | --- |
| 5 | 极高 | 该要素是主体的战略押注点（如竞品旗舰卖点、我方目标差异化核心） |
| 4 | 高 | 显著高于行业中位投入，客户可感知的领先 |
| 3 | 中等 | 行业标准水平（跟随者姿态） |
| 2 | 低 | 低于行业中位，客户可感知的短板 |
| 1 | 极低 | 几乎不投入（往往是 ERRC「消除/减少」候选） |

## 锚点示例

- **5 分正例**：健康监测精度——自研血压传感模组 + 三家三甲医院联合临床验证（押注点）
- **4 分正例**：续航能力——30 天续航，行业主流 10-14 天（可感知领先但非押注点）
- **3 分正例**：价格竞争力——定价处于行业中位带（跟随者姿态）
- **1 分正例**：奢侈品牌联名——无任何联名投入（合理的低投入，非短板）
- **1 分反例**：把「年报排版专业」评为要素水平（与客户价值无因果关联——此类条目不应进入要素清单）

## 聚合规则

- 价值要素清单以客户调研排序为准（客户关键购买因素 Top 5-8 项），不按内部能力偏好增删
- 我方目标曲线：目标水平经外部印证的行业定位校准（data_fusion.md），禁止全线拉满（价值曲线
  形态差异化是目标，不是高分堆叠）
- ERRC 判定：目标 < 当前 → 消除/减少候选；目标 > 当前且外部印证需求 → 增加/创造候选
