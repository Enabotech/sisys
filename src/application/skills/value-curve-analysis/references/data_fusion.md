# 价值曲线内外数据融合规范

> 本 Skill 的交叉验证主轴是「外部基准 ↔ 内部数据」：价值要素网格（客户调研采集）是分析主体，
> 外部源（Tavily/NewsAPI）仅提供竞品要素情报与市场动态的印证参照。

## 融合流程

1. **内部数据定基**：客户调研 + 三列网格（模板 `templates/value_curve_factors_grid.md`）确定价值要素
   清单与我方当前/目标水平——外部数据不新增我方要素水平判断（要素选取以客户调研共识为准）
2. **外部印证**：逐要素对照外部基准定位行业/竞品水平——
   - Tavily（竞品要素情报）：竞品在各要素上的投入强度/定价/服务水平（评测/规格/官网信息）
   - NewsAPI（市场动态）：要素偏好迁移信号（新品发布/价格战/监管要求的要素变化）
3. **曲线校准**：外部证据充分（≥1 源直接印证）时行业/竞品轮廓要素水平可上调；仅有内部认知时该要素
   定位下调一档并标注「未经外部印证」

## 冲突处理（外部基准与内部认知矛盾）

| 矛盾类型 | 处置 |
| --- | --- |
| 竞品外部情报显示要素水平高于内部判断 | 外部基准优先：修正竞品曲线该要素定位，修正前双方并列呈现于依据 |
| 内部判断竞品领先、外部无印证 | 双方并列呈现：保留内部定位 + 标注「未经外部印证」，不下结论 |
| 外部情报与客户调研方向相反 | 暂停判断：列入调研复议清单，以最新一手客户调研为准修正 |

## 内外结论权重

- **我方当前/目标曲线（内部主体）**：内部数据权重 100%（客户调研是要素水平的唯一裁判）
- **行业/竞品轮廓（外部象限）**：内部调研认知为分析主体，外部基准用于校准印证（非数值
  加权——价值曲线不做加权总分，R2-F8）；矛盾处置按冲突表分级裁决，校准结果并列呈现于曲线依据
- **ERRC 四行动**：以校准后的四主体曲线为输入，行动逻辑不受数据来源影响

## 基准粒度限制声明

Tavily/NewsAPI 为 Web 检索与新闻源，其覆盖是**行业事件级**而非**结构化指标级**：
- 适用于：竞品要素投入的事件性印证（新品发布/评测结论/定价变动/规格披露）
- 不适用于：要素水平的精确定量基准（如市占率/良率；需定量时结合 competitor-analysis 的多源链路）
- 时效边界：新闻源 TTL 24h/6h，超过 TTL 的曲线定位需重新采集印证
