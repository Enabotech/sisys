# 价值曲线客户调研与工作坊引导（2-4 小时结构化）

## 会前准备（T-3 天）

| 时点 | 动作 | 产出 |
| --- | --- | --- |
| T-3 天 | 分发客户调研问卷（关键购买因素排序）与 `templates/value_curve_factors_grid.md` 预填指引 | 客户调研回收 + 各自预填草稿（不汇总，防锚定） |
| T-2 天 | 收集内部数据材料：现行产品规格/定价表、竞品公开规格清单、上期差异化复盘 | 材料清单 |
| T-1 天 | 引导者汇总竞品动态速览（公开评测标题级，不预判要素水平） | 速览页（仅标题，不预判） |

## 现场流程（2-4 小时）

| 环节 | 时长 | 产出物 |
| --- | --- | --- |
| 开场与规则宣讲 | 15 min | 纪律共识（防锚定/防从众） |
| 价值要素清单定稿（客户购买因素） | 40 min | 要素清单（Top 5-8 项，客户调研排序为准） |
| 竞品清单与行业轮廓预绘 | 30 min | competitors 清单 + 行业曲线草稿 |
| 我方当前水平逐要素评审 | 40 min | value_factors 当前列 + 评分 |
| 我方目标水平设计（含 ERRC 讨论） | 40 min | value_factors 目标列 + 四行动候选 |
| 网格定稿与缺口登记 | 20 min | 模板定稿（含评分/证据/缺口登记） |
| 目标曲线预演（形态差异化检查） | 20 min | 目标曲线候选（Agent 深化输入） |

## 时间压缩指引（2 小时精简变体）

| 环节（精简版） | 时长 | 说明 |
| --- | --- | --- |
| 开场与规则宣讲 | 15 min | 纪律宣讲不可压缩 |
| 价值要素清单定稿 | 25 min | 要素上限 10 项（购买因素优先） |
| 竞品清单与行业轮廓预绘 | 15 min | 竞品上限 3 家 |
| 我方当前水平逐要素评审 | 25 min | 逐要素快评 |
| 我方目标水平设计（ERRC 精选） | 25 min | ERRC 仅讨论剔除/创造各 1 项 |
| 网格定稿与缺口登记（含预演） | 15 min | 形态差异化检查并入定稿 |

- **压缩代价**：要素与竞品覆盖面收窄，被裁项转入数据缺口登记区会后补采
- **不可压缩项**：防锚定/防从众纪律宣讲、证据来源登记、数据缺口登记——省略即失效

## 角色分工

- **引导者**：控流程/控时/执行纪律，不参与内容判断
- **业务专家**（2-4 人，产品/市场/客户成功跨职能）：要素水平评估主体
- **客户代表**（≥2 人，可选但推荐）：购买因素排序的最终裁判
- **记录员**：实时填写模板表格，逐条登记证据来源与数据缺口

## 引导纪律

- **防锚定**：预填草稿开场后才同时公开；禁止以「上年要素清单」为起点修修补补
- **防从众**：要素评分先独立举牌后讨论收敛；职级不参与评分权重
- **防溢出**：单要素讨论超 5 分钟即登记「待议」移入缺口登记区
- 每个要素必须落到模板行（要素/当前/目标三列 + 证据来源齐全才算完成）

## 会后跟进

1. 记录员 24h 内回收定稿模板，补齐缺口登记区的替代来源
2. 按模板「采集表格」字段构造 `input_schema` 参数：
   `competition_data.{competitors, value_factors}`（逐要素携带当前/目标水平与证据来源）
3. 调用本 Skill 执行：Agent 结合外部基准（Tavily/NewsAPI 双源印证）完成四主体曲线与 ERRC 四行动
4. 结果回传业务专家确认（重点：竞品要素定位与内部认知的矛盾项处置）
