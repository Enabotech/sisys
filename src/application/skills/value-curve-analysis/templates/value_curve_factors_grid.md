# 价值要素三列网格

> 客户调研与工作坊现场填写；采集字段与 SKILL.md `input_schema` 一一对应（竞争数据为嵌套分区，
> 分区内字段即 Schema 叶子键）。水平评分标准见 `references/scoring_anchors.md`。

## 基本信息

| 字段 | 说明 |
| --- | --- |
| 分析对象 | 目标产品/业务线名称 |
| 分析期间 | 如 2026-2030 战略周期 |
| 调研/工作坊日期 | 填写日期 |
| 引导者/记录员 | 名字 |

## 采集表格

### competition_data

竞品清单（逐竞品一行，行业战略轮廓绘制对象）：

| 字段 | 竞品名称 | 关注理由 |
| --- | --- | --- |
| competitors（必填） | 华为 Watch GT 系列 | 行业健康要素押注代表 |
| competitors（必填） | 小米手环 Pro | 价格带锚点主体 |

价值要素三列网格（逐要素一行，要素名 → 我方当前水平/目标值）：

| 字段 | 要素名称 | 当前水平（1-5） | 目标水平（1-5） | 证据来源 |
| --- | --- | --- | --- | --- |
| value_factors（必填） | 价格竞争力 | 3 | 4 | 定价表 2026-Q2 |
| value_factors（必填） | 健康监测精度 | 2 | 5 | 客户调研 Top2 购买因素 |
| value_factors（必填） | 续航能力 | 4 | 4 | 产品规格书 |
| value_factors（必填） | 生态互联 | 2 | 3 | 客户调研 |

> 行示例可替换；多竞品/多要素时逐行扩展，每行首列字段名与「（必填）」标注保持一致。

## 评分锚点

价值要素水平刻度（1-5）与每档判定标准、正反例锚点见 `references/scoring_anchors.md`；
外部印证后的曲线校准规则见 `references/data_fusion.md`。

## 数据缺口登记

| 字段 | 缺口描述 | 替代来源 |
| --- | --- | --- |
| value_factors | 竞品健康监测精度的定量口径缺口（各厂传感方案不透明） | 外部 Agent 采集印证 / 第三方拆解报告 |
| competitors | 价格带锚点竞品的渠道定价数据缺口 | 行业协会零售监测 / 公开电商价签 |
