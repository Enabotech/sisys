# GE-麦肯锡矩阵内外数据融合规范

> 本 Skill 的交叉验证主轴是「外部基准 ↔ 内部评分」：业务单元评分表（高管访谈采集）是分析主体，
> 外部源（World Bank/Tavily）仅支撑行业吸引力维度的印证参照。

## 融合流程

1. **内部评分定基**：高管访谈评分表（模板 `templates/ge_business_unit_scoresheet.md`）
   是双维评分的骨架——`competitive_strength`（业务实力）以内部数据为准，
   外部源不新增/不改写实力评分（内部能力判断以访谈共识为准）
2. **外部印证**：`industry_attractiveness`（行业吸引力）逐项对照外部基准——
   - World Bank（宏观基本面）：目标行业所处经济体的 GDP/投资/收入类指标，
     为行业规模与增速提供宏观锚定
   - Tavily（市场情报）：行业增速/竞争烈度/新兴需求事件，为吸引力方向性判断提供佐证
3. **评分校准**：外部证据充分（≥1 源直接印证）时吸引力评分可上调/下调一档；
   仅有内部判断时评分下调一档并标注「未经外部印证」

## 冲突处理（外部基准与内部评分矛盾）

| 矛盾类型 | 处置 |
| --- | --- |
| 外部有证据、内部评分未反映（漏判的行业机会/风险） | 外部基准优先：调整吸引力候选评分，标注「外部信号，待高管复议」 |
| 内部评分高、外部无印证 | 双方并列呈现：保留内部评分 + 标注「未经外部印证」，不下结论 |
| 外部情报与内部评分方向相反 | 暂停判断：列入访谈复议清单，以最新一手内部数据为准修正 |

## 内外结论权重

- **业务实力（内部维度）**：内部数据权重 100%（外部源不评判内部实力）
- **行业吸引力（外部维度）**：外部印证权重 70% / 内部判断 30%——外部基准修正内部判断，
  修正前双方并列呈现于九宫格定位依据
- **九宫格定位与投资建议**：以校准后的双维评分为输入，定位逻辑不受数据来源影响

## 基准粒度限制声明

World Bank 宏观指标是**国家/经济体维度**而非行业维度：GDP/投资类指标只能锚定
行业所处的大盘环境，不能直接当作行业增速使用（推断须经「宏观 → 行业」的显式映射并标注假设）。
Tavily 为 Web 检索源，其覆盖是**行业事件级**而非**结构化指标级**：适用于增速方向/竞争事件的
定性印证，不适用于市场规模定量基准。时效边界：WB 指标 TTL 7 天 / Tavily TTL 24h，
超过 TTL 的结论需重新采集印证。
