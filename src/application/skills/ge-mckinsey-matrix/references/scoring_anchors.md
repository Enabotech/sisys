# GE 矩阵双维评分锚点（1-10 刻度）

> 刻度声明：本 Skill 采用 **1-10 刻度**（可用 0.5 步进），行业吸引力（外部维度，经
> World Bank/Tavily 印证校准）与业务实力（内部维度，内部数据为准）分别独立评分。
> 评分主体为高管访谈业务负责人（引导者防锚定，见 workshop_guide.md）。

## 行业吸引力分档（外部维度）

| 分值 | 档位 | 判定标准 |
| --- | --- | --- |
| 9-10 | 高吸引力 | 行业增速远超 GDP 增速且政策/需求双顺风，容量足以容纳 3 家以上盈利玩家 |
| 6-8 | 中高吸引力 | 行业增速高于大盘，竞争格局未固化，存在结构性机会 |
| 4-5 | 中等吸引力 | 行业增速与大盘持平，盈利水平行业分化明显 |
| 2-3 | 低吸引力 | 行业负增长或严重产能过剩，价格战常态化 |
| 1 | 极低吸引力 | 行业进入衰退/替代期，需求趋势性萎缩 |

## 业务实力分档（内部维度）

| 分值 | 档位 | 判定标准 |
| --- | --- | --- |
| 9-10 | 领先 | 相对市场份额第 1 且成本/利润率显著优于行业中位 |
| 6-8 | 强 | 相对份额前 3，利润率不低于行业中位，具备可复制的能力壁垒 |
| 4-5 | 中等 | 份额居中，盈利依赖周期，能力壁垒不明显 |
| 2-3 | 弱 | 份额后段，利润率持续低于行业中位 |
| 1 | 极弱 | 持续亏损或份额边缘化，无差异化能力 |

## 锚点示例

- **吸引力 9 分正例**：动力电池行业——储能与电动车双轮驱动，需求年增 30%+（WB 宏观 + Tavily 情报双印证）
- **吸引力 4 分反例**：仅因「国家 GDP 增长 5%」直接推定行业吸引力 9 分（国家维度≠行业维度，见 data_fusion.md）
- **实力 8 分正例**：消费电池单元——份额行业第 2、毛利率高于行业中位 5pct（内部财务数据支撑）
- **实力 6 分反例**：把「行业整体景气」计入本单元实力分（景气属外部维度，混维即无效评分）

## 聚合规则

- 双维评分不合并为单一总分（GE 矩阵以坐标定位而非总分排序）
- 九宫格切分（档界对齐 0.5 步进可达网格，消除 6.0-6.67 双归属）：每维按
  ≤3 / 3.5-6.5 / ≥7 三档（低/中/高），交叉得 9 宫格；上表五档分带为描述粒度，
  归档按三档执行（9-10 与 7-8 → 高，6.5-3.5 → 中，3-1 → 低）
- 投资建议映射（经典 GE 三带全覆盖，替代原三条角落规则——原「高低组合 →
  选择性发展/收割」可使高吸引弱实力业务被误判收割，业界 GE 惯例禁对高吸引业务收割）：
  - **投资/增长（绿带）**：高吸引×强实力、高吸引×中实力、中吸引×强实力
  - **选择性发展（黄带）**：高吸引×弱实力（设定补强里程碑，无法补强再议退出——禁收割）、
    中吸引×中实力（选择性投资）、低吸引×强实力（保护性收割/专注现金流）
  - **收割/退出（红带）**：中吸引×弱实力、低吸引×中实力、低吸引×弱实力
  - 一句话规则（与三带表精确等价）：按档位赋值（高 3 / 中 2 / 低 1），两维之和
    ≥5 → 投资/增长；=4（高×低、中×中、低×高对角线）→ 选择性发展；
    ≤3 → 收割/退出侧（边界情形按校准后评分与复议结论裁定，
    禁止仅凭单维极值定档）
- 校准幅度定义：「上调/下调一档」= 1.0 分（0.5 步进刻度下的整档）；
  校准后评分变化超过 1 分的，须在定位依据中登记印证来源
